# API печати для ботов

Общий сервер: `https://evpmerch.com:9443`. Все операции бота используют отдельный
заголовок `X-Print-Key`. Администратор выдаёт каждому боту свой отзывной ключ
с явным списком принтеров. Ключ заказов `X-Admin-Key` ботам не передаётся.
Ключ показывается один раз при создании; в БД остаётся только SHA-256.
Не записывайте заголовки авторизации и base64-файлы в журналы.

## Принтеры и выбор

`GET /api/print/v1/printers` возвращает `stations` и сохранённый `destination`.
Видны только разрешённые принтеры. Станция содержит `id`, `name`, `online`,
`lastSeen`, `printers`. Профиль содержит `id`, `name`, `paperMode`,
`labelHeightMm`; `documentVersion: 1` означает поддержку файлов новой станцией.
Онлайн означает связь с модулем, а не наличие бумаги или исправность механизма.

`PUT /api/print/v1/destination` сохраняет общий выбор для ключа:

```json
{"stationId":"UUID станции","printerId":"24 hex символа профиля"}
```

`GET /api/print/v1/destination` возвращает `{ "destination": ... }`.
Выбор можно сохранять в самом боте по пользователю и передавать в каждом задании.
СДЭК-бот использует персональный выбор `/printer`, затем общий выбор ключа.

## Отправка

`POST /api/print/v1/jobs` → HTTP 202:

```json
{
  "clientKey": "UUID неизменяемого задания",
  "stationId": "UUID станции (можно опустить вместе с printerId)",
  "printerId": "ID профиля",
  "document": {"mimeType": "application/pdf", "dataBase64": "JVBERi0..."}
}
```

Допустимы PDF без пароля из 1–8 страниц и обычный PNG, до 8 МиБ исходного файла.
Каждая страница PDF должна иметь размеры 20–300 мм. Ограничены размеры изображений,
время обработки (25 секунд), параллельная подготовка и частота заданий.
Произвольные URL, SVG, пути файлов и RAW/ZPL/ESC-команды API не принимает.
PDF рендерится PDF.js в отдельном процессе; станция получает только проверенные PNG.
Рендерер использует локальные шрифты из пакета PDF.js, без загрузки внешних ресурсов.

Для термопринтера страница вписывается в зарегистрированные 80×110/120 мм при
203.2 dpi (8 точек/мм), без обрезки и изменения пропорций. A6 СДЭК 105×148 мм
на Zebra 80×120 занимает около 80×112.8 мм. Профиль `sheet` печатает A6
105×148 мм в масштабе 1:1 на A4 при 300 dpi. PNG вписывается по пропорциям пикселей.
Несколько страниц передаются Windows одним заданием. Баркоды не перерисовываются
по распознанному тексту: печатается оригинальное содержимое этикетки.

## Идемпотентность и статус

Сохраните `clientKey` **до** первого POST и повторяйте его для того же файла и
того же назначения. Повтор возвращает существующее задание, включая завершённое;
тот же UUID для другого файла, назначения или бота даёт 409. Таймаут POST не доказывает,
что задание не принято: проверяйте `GET /api/print/v1/jobs/{clientKey}` и при 404
повторяйте исходный POST с тем же UUID. Выбранное назначение также надо сохранить.
Не генерируйте новый UUID при таймауте, двойном нажатии или перезапуске.

СДЭК-бот сохраняет PDF в SQLite, использует стабильный UUID для этикетки отправления,
фиксирует назначение перед POST и защищает создание отправления отдельной долговечной
записью по сообщению диалога. Повторная кнопка не создаёт новое отправление.

| status | Значение |
|---|---|
| `queued` | Сервер принял задание, модуль его ещё не получил. |
| `claimed` | Модуль получил задание; итог ещё неизвестен. |
| `submitted` | Windows/драйвер принял задание. Выход бумаги не подтверждён. |
| `failed` | Задание не передано Windows или истекло до получения. |
| `uncertain` | Печать могла начаться, подтверждение потеряно; проверьте бумагу и очередь. |

Ответ содержит `message`, `error`, `physicalOutputConfirmed: false`, `pageCount`,
`sourceSha256`, `sourcePages`, размеры назначения и замеры времени. Содержимого
файла и ключа в статусе нет. Чужие задания возвращают 404.
Неполученное задание истекает через 90 секунд; потеря связи после получения
переводит его в `uncertain`. Станция хранит локальный журнал до вызова драйвера;
после сбоя и потери подтверждения автоматической повторной печати нет.
Позднее подтверждение станции может уточнить `uncertain`.

HTTP 403 — неверный/отозванный ключ или запрещённый принтер; 409 — конфликт UUID,
ПК офлайн, старый модуль или изменённая настройка; 422 — файл не обработан;
429 — очередь занята. При ошибке PDF остаётся у бота. Завершённое `failed` сохраняет
UUID: новое задание допустимо лишь как осознанная отдельная печать после проверки.

## Выдача и отзыв ключей (только администратор)

`POST /api/network-printing/clients` с `X-Admin-Key`:

```json
{
  "name":"cdek-bot",
  "printers":[{"stationId":"UUID","printerId":"ID"}],
  "destination":{"stationId":"UUID","printerId":"ID"}
}
```

Ответ 201 содержит `id` и одноразовое поле `key`. Сохраните его сразу в защищённой
конфигурации нужного бота. `GET /api/network-printing/clients` ключей не возвращает.
`DELETE /api/network-printing/clients/{id}` отзывает ключ и отменяет его ещё
не полученные задания. Уже полученное станцией задание может успеть напечататься.
Создание нового ключа не меняет существующие задания старого ключа.

Перед включением файлов обновите Windows-модуль на ПК с принтером через
`Update.cmd` из нового ZIP. Реестр станций и история сохраняются. Старая станция
продолжает печатать внутренние этикетки сайта; файловый API требует новую версию.

Пример другого бота: [print-label.py](../examples/print-label.py).
