ПЕЧАТЬ ЭТИКЕТОК НА ДРУГОМ КОМПЬЮТЕРЕ

1. Установите драйвер принтера в Windows. Принтер должен быть виден в списке принтеров Windows.
2. Распакуйте весь ZIP в папку и запустите Install.cmd из этой папки.
   Не запускайте файл непосредственно из открытого архива.
3. Введите ключ рабочего сервера. Адрес уже заполнен: https://evpmerch.com:9443
4. Откроется сайт. Нажмите шестерёнку. Для маленьких меток выберите
   «Маленькая · 45×22,5 мм», ниже в «Метки · 45×22,5 мм» — ваш XP-365.
   Нажмите «Сохранить принтер».
5. Кнопка «Этикетка» теперь отправляет задание прямо в очередь Windows.

В дальнейшем открывайте ярлык «Заказы» на рабочем столе.
Если Windows не разрешила создать ярлык .lnk, установка и запуск продолжатся.
Для открытия заказов запустите Open.cmd из распакованного пакета.
Недостающие папки ярлыков создаются автоматически. При недоступной папке
автозагрузки используется резервный автозапуск текущего пользователя Windows.
Этот вариант включается только при отмеченной галочке автозапуска.
Подробности ошибок ярлыков: %LOCALAPPDATA%\VanyaTools\OrderStation\data\shortcut-warnings.txt.
Локальный адрес: http://127.0.0.1:4174/orders
При входе в Windows модуль запускается автоматически, если опция включена при установке.
Он работает в фоне и не требует установленного Node.js или CorelDRAW.
Интерфейс загружается с рабочего сервера и получает его обновления.

ОБЩИЕ ПРИНТЕРЫ — ПЕЧАТЬ С ДРУГИХ ПК

Выбранные в настройках принтеры автоматически регистрируются на рабочем сервере.
В шестерёнке раздел «Общие принтеры» доступен с любого ПК на сайте:
  https://evpmerch.com:9443/orders
Выберите «имя рабочего места · принтер» для нужного размера этикетки.
Название ПК можно изменить в разделе «Рабочие места», например на «Термопресс».
Выбор сохраняется в браузере. Кнопка «Этикетка» отправляет задание без нового окна.
Модуль устанавливается только на компьютеры, к которым подключены принтеры.
Для обновления старого модуля распакуйте новый ZIP и снова запустите Install.cmd.
Если модуль уже настроен, Update.cmd обновит его без повторного ввода ключа.
Настройки подключения, идентификатор рабочего места и история сохраняются.
В настройках сайта можно отметить дополнительные принтеры 80×120 мм:
они появятся в общей очереди рядом с основным принтером и маленькими метками.
Маленькая стрелка у кнопки «Этикетка» выбирает принтер без открытия настроек;
последний выбор запоминается в браузере отдельно для каждого формата.
Полная этикетка теперь 80×120 мм, без QR. Штрихкод печатается крупно,
полосами в целых точках принтера без сглаживания, при родном разрешении драйвера.
Для новой бумаги обновите модуль на каждом ПК с принтером и выберите полную
этикетку в настройках сайта. Размер маленькой метки остаётся 45×22,5 мм.
На ПК с принтером должен работать модуль, а Windows — не находиться в спящем режиме.
Открытая вкладка браузера на этом ПК для получения заданий не нужна.

Результат «Передано в очередь Windows» означает успешную отправку задания драйверу.
Наличие бумаги и фактический выход этикетки проверьте у принтера.
Если ПК не в сети, задание не создаётся. Неполученные задания истекают через 90 секунд.
Без выбора общего принтера остаётся прежняя локальная печать или диалог браузера.

Ключ зашифрован средствами Windows для текущего пользователя.
В этом пакете нет ключей, базы заказов или токена Telegram-бота.
Обновление 06.11.2026: поддержка PDF/PNG из внешних ботов через общий API.
На ПК с выбранной Zebra распакуйте весь ZIP и запустите Update.cmd.
Подключение, выбранные принтеры и журнал уже обработанных заданий сохраняются.
PDF СДЭК A6 помещается на 80x120 мм целиком, с сохранением пропорций.
До обновления модуль не объявляет поддержку файлов, и API их не принимает.
Заказы хранятся на рабочем сервере. На ПК сохраняются только настройки и история печати.

При потере ответа во время печати проверьте бумагу и очередь Windows перед повтором.
Модуль не повторяет автоматически прерванные задания после перезапуска.

Обновление 29.10.2026: ограничен размер растрового изображения этикетки.
Для Xprinter XP-365B и XP-370B/370BM полная 80×120 печатается в родных
640×960 точках; устранено лишнее увеличение растра перед передачей драйверу.
Отправку выполняет компактный модуль .NET без запуска PowerShell для каждой
этикетки. Драйверы Windows и их настройки подачи бумаги сохраняются.
Кратковременная блокировка файла истории Windows обрабатывается повтором
сохранения. Само задание печати при этом повторно не отправляется.
Если подача бумаги или отделитель работают неправильно, запустите
Diagnose-Printers.cmd из распакованного архива. Он сохранит printer-diagnostics.json
с размерами бумаги, драйверами и состоянием очередей, не печатая этикеток.

Настройки подключения и автозапуска: ярлык «Настройки печати заказов».
Остановить модуль: powershell -NoProfile -ExecutionPolicy Bypass -File
  "%LOCALAPPDATA%\VanyaTools\OrderStation\station.ps1" -Mode Stop
