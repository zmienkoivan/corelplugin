# Шаблон спортформы для Vanya Tools

Один файл CDR содержит **одну страницу**. Каждый слой лекал обозначает один размер и имеет уникальное имя. Именно эти имена появятся в списке размеров таблицы игроков. Поля переменной информации храните отдельно для каждого размера: для слоя `S` — `VT_ZONES_S`, для `M` — `VT_ZONES_M`, для `128` — `VT_ZONES_128`. Имена объектов на этих слоях одинаковы, но их положение и оформление независимы. Общий слой `VT_ZONES` необязателен и поддерживается для старых моделей.

```mermaid
flowchart TB
    page["CDR · одна страница"]
    zonesS["VT_ZONES_S · поля размера S"]
    zonesM["VT_ZONES_M · поля размера M"]
    zonesXL["VT_ZONES_XL · поля размера XL"]
    s["Слой S"]
    m["Слой M"]
    xl["Слой XL"]
    groupS["Группа VT_TOP · 5 деталей S"]
    groupM["Группа VT_TOP · 5 деталей M"]
    groupXL["Группа VT_TOP · 5 деталей XL"]
    page --> zonesS
    page --> zonesM
    page --> zonesXL
    page --> s --> groupS
    page --> m --> groupM
    page --> xl --> groupXL
```

Размеры `S`, `M`, `XL` приведены для примера. Вы можете назвать слои иначе. Если одновременно видны лекала нескольких размеров, временно скрывайте лишние слои при подготовке файла; сохранённый CDR может содержать все слои.

На каждом слое размера должна быть одна группа `VT_TOP` с **ровно пятью группами деталей**:

| Объект | Деталь |
| --- | --- |
| `VT_FRONT` | полка |
| `VT_BACK` | спинка |
| `VT_SLEEVE_LEFT` | левый рукав |
| `VT_SLEEVE_RIGHT` | правый рукав |
| `VT_NECK` | горловина |

Внутри каждой группы детали находится один **замкнутый векторный контур `silhouette`**. Он задаёт внешний силуэт детали. Там же могут находиться другие кривые — надсечки и линии для резки; их имена произвольные. Для резки поддерживаются кривые и обычные векторные фигуры Corel. Зоны и текстовые образцы размещайте на персональном `VT_ZONES_<размер>` вне `VT_TOP`.

`silhouette` также может быть векторной фигурой Corel: например, прямоугольником горловины. Для печати в кривую переводится только её временная копия, после чего строится наружный контур +6 мм. В резке исходная фигура сохраняется как есть вместе со всеми остальными кривыми группы. Сам поиск `silhouette` не проверяет остальные объекты группы; состав линий резки проверяется при создании раскладки резки.

```text
Слой размера (например, 128)
└── VT_TOP
    ├── VT_FRONT
    │   ├── silhouette
    │   └── остальные кривые резки
    ├── VT_BACK
    │   ├── silhouette
    │   └── остальные кривые резки
    ├── VT_SLEEVE_LEFT
    │   ├── silhouette
    │   ├── надсечка 1
    │   └── надсечка 2
    ├── VT_SLEEVE_RIGHT
    │   ├── silhouette
    │   └── надсечки
    └── VT_NECK
        └── silhouette
```

**Печать:** первый этап создаёт отдельную кривую со сдвигом наружу на **6 мм** от `silhouette`. Это настоящий наружный контур, а не увеличение габаритов. Он становится контейнером для рисунка и определяет габариты печатной раскладки. Сдвиг применяется после масштабирования размера, поэтому остаётся 6 мм при любом масштабе. Исходная группа резки сохраняется целиком рядом с контейнером и именуется `VT_SPORT_CUT_FRONT`, `VT_SPORT_CUT_BACK`, `VT_SPORT_CUT_LEFT_SLEEVE`, `VT_SPORT_CUT_RIGHT_SLEEVE` или `VT_SPORT_CUT_NECK`. Подпись в подгибке располагается относительно исходного силуэта, а не края увеличенного контейнера.

**Резка:** копируются **все кривые исходной группы**, в том числе сама `silhouette` и мелкие надсечки, без сдвига контура и изменения взаимного положения. Рисунки, печатный контейнер +6 мм, рамки нанесения и печатные надписи в резку не попадают. При отключённых ушках кривые остаются исходными. При включённых ушках на копии `silhouette` изменяются только два коротких участка прямого края для перемычек, добавляются контур ушка и прорезной размер. Имена игрока, размера и детали также сохраняются в именах групп.

Прежние шаблоны, в которых деталь была одной кривой вместо группы, поддерживаются: эта кривая используется как исходный силуэт и как линия резки.

На каждом персональном слое `VT_ZONES_<имя слоя размера>` разместите следующие объекты. Имена объектов сохраняются прежними, поэтому прямоугольник можно заменить текстом с тем же именем.

Для перехода старой модели откройте её исходную страницу в Corel и нажмите **«Лекала → Создать персональные поля в модели»**. Для каждого слоя с `VT_TOP` создаётся независимая копия общих полей. Если поля уже находятся непосредственно на слое размера вне `VT_TOP`, копируются они. Существующие персональные слои не меняются, поэтому повторный запуск добавляет только недостающие. Отредактируйте поля с учётом каждого размера и сохраните CDR модели.

Приоритет чтения: персональный слой `VT_ZONES_<размер>` целиком; иначе — поля на самом слое размера вне `VT_TOP`; иначе — старый общий `VT_ZONES`. Отсутствующее поле из персонального набора не дополняется общим. Даже пустой персональный слой имеет приоритет и отключает все поля этого размера. Вложенные группы образцов допускаются; внутри `VT_TOP` полей быть не должно.

| Имя объекта | Содержимое |
| --- | --- |
| `VT_SPORT_ZONE_FRONT_LEFT` | текстовый образец имени слева на груди |
| `VT_SPORT_ZONE_FRONT_RIGHT` | текстовый образец имени справа на груди |
| `VT_SPORT_ZONE_BACK` | отдельный текстовый образец имени на спине |
| `VT_SPORT_ZONE_BACK_NUMBER` | отдельный текстовый образец номера на спине |
| `VT_SPORT_ZONE_LEFT_SLEEVE` | текстовый образец номера или прямоугольник для графики левого рукава |
| `VT_SPORT_ZONE_RIGHT_SLEEVE` | текстовый образец номера или прямоугольник для графики правого рукава |
| `VT_SPORT_ZONE_NECK` | необязательный текстовый образец номера или прямоугольник для графики горловины |

Образец — обычный **фигурный текст**, который остаётся текстом. Для имени напишите `XXXXXXXXX`, для двух строк имени — две строки `XXXXXXXXX` в одном текстовом объекте. Для номера используйте `XX` или `XXX`. Выберите шрифт, кегль, начертание, цвет, обводку, выравнивание и межстрочный интервал средствами Corel. Текст не нужно переводить в кривые или группировать с рамкой.

Генерация копирует оформление каждой строки образца. Короткие имена и номера сохраняют его кегль; слишком широкие пропорционально уменьшаются до ширины образца. Итоговая надпись располагается по центру его области. В двухстрочном имени перенос идёт после первого слова; символ `|` в таблице позволяет выбрать перенос вручную. Пустые данные и образец на невыбранной стороне груди не оставляют символов X в печати.

Положение образцов и рамок настраивайте под контур своего размера в исходной модели. После этапа 1 их также можно двигать и оформлять отдельно в готовом макете. Для назначения поля создайте и выделите фигурный текст на слое размера или на его персональном слое, затем нажмите нужную кнопку: имя груди слева/справа, имя/номер спины, номер левого/правого рукава или горловины. Кнопка заменяет только поле своего размера. При назначении прямо на исходном слое размера образец переносится на его персональный слой; если слоя ещё нет, он создаётся с копиями прежних полей. В готовом макете поле остаётся на слое этого размера.

Все текстовые области необязательны. Удалите ненужный объект с персонального слоя, чтобы пропустить его только для этого размера. В старой модели без персональных полей удаление с общего `VT_ZONES` действует на все размеры. Удаление с отдельного слоя готовой обзорной страницы действует только на этот макет. Например, можно убрать `VT_SPORT_ZONE_RIGHT_SLEEVE` у маленьких размеров. Этап 2 не создаёт удалённые поля заново; имя на спине и номер на спине работают независимо. Готовые макеты не обновляются автоматически после изменения исходной модели: поправьте их поля непосредственно либо удалите слой нужного размера на обзорной странице и повторите этап 1.

Этап 1 также создаёт фигурные текстовые образцы подписей в подгибке каждой детали: `VT_SPORT_CAPTION_FRONT`, `VT_SPORT_CAPTION_BACK`, `VT_SPORT_CAPTION_LEFT_SLEEVE`, `VT_SPORT_CAPTION_RIGHT_SLEEVE`, `VT_SPORT_CAPTION_NECK`. В образце видны `XXXXXXXXX · №XX · размер · деталь`. Меняйте шрифт, кегль, цвет, обводку и положение на слое размера. Этап 2 подставляет данные игрока, сохраняет оформление и левый нижний край образца; слишком длинная подпись уменьшается до его ширины. Удалённая подпись также пропускается. Эти изменения требуют нового запуска этапа 1; у старых обзорных страниц сохраняются автоматические подписи прежнего вида.

Шрифт, кегль, наклон, начертание, цвет, обводку и интервалы меняйте в текстовом образце средствами Corel. Выбор шрифта и начертания из вкладки спортформы удалён. Текстовые образцы берут оформление и количество строк из CDR. Прежние макеты с прямоугольниками поддерживаются с оформлением старого черновика; для новых макетов используйте текстовые образцы.

Во вкладке «Спортформа» нажмите «Выбрать модель CDR», заполните таблицу игроков и назначьте размеры. **Этап 1 использует только размеры строк с галочкой «Печатать»**. Несколько игроков одного размера требуют одного макета. Например, для отмеченных S и M готовятся только S и M; остальные размеры модели не копируются и не импортируют рисунки. Для выбранной строки без размера или без соответствующего шаблона появится сообщение до открытия моделей.

Первый запуск создаёт в текущем документе одну обзорную страницу: **два столбца целых комплектов размеров**, следующая пара располагается ниже. Порядок слева направо и сверху вниз соответствует таблице размеров. Каждая ячейка содержит все детали одного размера, рисунки, зоны нанесения, подписи и название размера; масштаб деталей сохраняется. Размер остаётся на отдельном слое. Ширина столбцов и высота каждого ряда определяются по полным габаритам комплектов, расстояние между ячейками — 40 мм, поля страницы — 20 мм. Страница сначала получает итоговый размер, затем комплекты размещаются от её фактического верхнего левого угла.

**Повторный этап 1 добавляет только недостающие размеры на ту же страницу.** После подготовки S и M можно добавить игрока размера L, отметить его и повторить этап 1: создаётся только L. Готовые слои сохраняют рисунки, текстовые образцы, удалённые необязательные поля, подписи и ручное расположение. Новые комплекты занимают свободную ячейку последнего ряда либо продолжают сетку ниже; при увеличении страницы сохраняется положение готовых объектов относительно страницы. Если все отмеченные размеры уже готовы, модели не открываются, рисунки не импортируются, страница только активируется. Старые обзорные страницы из прежних версий распознаются. Неотмеченные строки не добавляют размеры; ранее созданные слои автоматически не удаляются. Для намеренного пересоздания одного размера удалите его слой на обзорной странице и повторите этап 1 с отмеченной строкой этого размера.

На обзорной странице можно отдельно поправить рисунки, контуры и текстовые образцы. Второй этап берёт эти правки и создаёт страницу печати указанной ширины. Для плотной укладки разрешите поворот рукавов и горловины на 90° только если направление рисунка и ткани это допускает.

## Вставка таблицы игроков

Скопируйте диапазон любого количества строк из Excel или Google Таблиц и нажмите `Ctrl+V` в выбранной ячейке редактора. Значения заменят соответствующие ячейки, недостающие строки добавятся автоматически. Можно вставить только столбец имён или номеров, начиная с нужной ячейки: остальные данные существующих строк сохранятся. Кнопка «Добавить из Excel / Google Таблиц» добавляет весь диапазон в конец таблицы. «Убрать строки» удаляет все строки выбранного диапазона.

Если копируете только столбец имён, вставьте его в пустую таблицу или нажмите «Добавить из Excel / Google Таблиц». Все имена попадут в столбец «Имя», новые строки останутся без размера и с количеством 1. Размеры назначьте после вставки: выделите группу ячеек с Shift или несколько строк с Ctrl, выберите «Размер выделенным» и нажмите «Назначить». Можно по-прежнему выбирать размер в каждой строке. Генерация попросит заполнить оставшиеся пустые размеры. Одиночный столбец размеров или номеров вставляйте в соответствующие ячейки либо копируйте вместе с заголовком «Размер» или «№».

Без заголовков порядок столбцов: **размер, имя, номер, количество**. С заголовками порядок произвольный: распознаются «Размер»/«Рост», «Имя»/«ФИО», «Номер»/«№», «Количество»/«Шт.». Отдельные столбцы «Фамилия» и «Имя» объединяются. Размер должен совпадать с именем слоя; числовой рост, например `152`, также подходит, если в модели есть ровно один слой с этим числом в конце имени. Пустое количество означает один комплект; номера вроде `007` сохраняются текстом. Пустые строки пропускаются, переносы внутри скопированных текстовых ячеек поддерживаются. Если найдены некорректные размеры или количества, весь диапазон остаётся без изменений и выводится номер строки с ошибкой.

## Выбор деталей печати

В таблице игроков у каждой строки есть галочки **«Перед»**, **«Спина»**, **«Лев. рук.»**, **«Прав. рук.»**, **«Горловина»**. Они ограничивают печать деталей этой строки; в резку входят все детали исходного комплекта, включая снятые с печати. Общая галочка **«Печатать»** по-прежнему выбирает строку заказа для обоих действий.

Галочка в заголовке столбца включает или выключает деталь у всех строк. Например, снимите **«Лев. рук.»** и **«Горловина»** в заголовках: печать будет содержать перед, спину и правый рукав, а резка — весь комплект. Если сняты все галочки деталей, строка пропускается при печати и сохраняется для резки. В старых черновиках все детали включены. Вставка поверх строк сохраняет их выбор деталей; новые строки получают все включённые галочки. Изменение выбора деталей сбрасывает отметки печати/PDF, сохраняя отметку резки. Кнопка **↗** остаётся явным запросом одной детали для допечатки независимо от галочки.

## Раскладка резки

В разделе «Раскладка резки» нажмите «Создать раскладку резки». Размеры и количество комплектов берутся из таблицы игроков, ширина полотна и расстояние — из общих настроек. Детали размещаются с учётом контуров на отдельной странице текущего CDR, без отступа от края. Галочка «Разрешить поворот деталей резки на 180°» разрешает автоматический выбор между 0° и 180° для каждой детали. Поворота на 90° для резки нет; при отключённой галочке сохраняется исходное направление.

При уплотнении учитываются `silhouette` и остальные линии детали, включая надсечки. Профиль строится с шагом до 2 мм; для кривых Безье используются покрывающие границу области, чтобы не уменьшать реальный зазор. По всей высоте каждой страницы сохраняются занятые интервалы: рукава и горловины могут заполнять промежутки между ранее размещёнными деталями. Скосы и дуги рукавов учитываются при проверке столкновений. Исходные узлы и кривые не меняются. Для резки рассматриваются только исходное направление и разрешённый галочкой поворот на 180°.

## Вкладки раскладки и отметки шагов

Инструмент разделён на пять вкладок в одной строке сверху: **Лекала**, **Рисунки**, **Игроки**, **Печать**, **Резка**. Экспорт PDF расположен вместе с созданием печатной раскладки в «Печати». У каждой вкладки собственная вертикальная прокрутка, поэтому заголовки остаются на месте. Последняя открытая вкладка запоминается в черновике; старые значения вкладок PDF и резки переносятся в новые позиции автоматически. Общий результат операции виден под вкладками. Экспорт DXF, сохранение CDR резки и лист пробных язычков находятся в «Резке»; большое окно игроков доступно в «Игроках».

Зелёная галочка в заголовке «Лекала» означает, что назначены размеры и файлы CDR, а в «Игроках» — что отмеченные строки имеют допустимые размеры, количество и длину текста. Эти отметки отражают заполнение настроек; наличие геометрии проверяется при подготовке. «Рисунки» отмечаются после успешной подготовки макетов выбранных размеров, «Печать» — после создания полной печатной раскладки или экспорта активного листа в PDF, «Резка» — после создания раскладки или успешного сохранения активного листа в CDR/DXF. Экспорт PDF также отмечается строкой рядом с кнопкой. Наведение на вкладку показывает, какое действие выполнено. Создание одной детали для допечатки или пробных язычков не отмечает полную раскладку.

При изменении лекал, рисунков, выбранных размеров, игроков и настроек снимаются отметки соответствующих зависимых шагов. Изменение имени или количества не требует повторной подготовки макетов того же набора размеров, но снимает отметки готовой печати, PDF и резки. Плотность и группировка независимы: изменение этих настроек в «Резке» снимает только отметку резки, а в «Печати» — только отметки печати и PDF. Новая печатная раскладка снимает прежнюю отметку PDF. Во время операции настройки временно недоступны, чтобы её результат соответствовал выбранным данным.

Отметки действий, сведения об их настройках и собственный идентификатор хранятся в отдельных [пользовательских свойствах CDR](https://community.coreldraw.com/sdk/api/draw/19/p/document.properties?lang=vb). Сохраните рабочий CDR, чтобы оставить отметки после закрытия Corel. При переключении документов загружается состояние соответствующего CDR; повторная выдача Corel нового COM-объекта и кратковременное отсутствие активного документа не снимают отметки. Старое сравнение сырых COM-указателей раз в секунду удалено. Если Corel не позволяет записать свойства, отметка остаётся в текущем интерфейсе, причина записывается в журнал. Сохранение отметок не сохраняет сам файл автоматически.

Ручные правки средствами Corel, Undo и удаление объектов не проверяются автоматически по галочкам. Отметка PDF относится к экспорту **одного активного листа**: если листов несколько, экспортируйте каждый отдельно. Для макетов из 1.1.28, в которых отметки ещё не были записаны в CDR, повторите подготовку выбранных размеров: существующие слои сохранятся, а успешное действие получит новую отметку.

### Плотность и группировка деталей

Плотность и группировка задаются отдельно в «Печати» и «Резке» и независимо запоминаются в черновике. Например, печать можно укладывать свободно по полному контуру, а резку — парами по упрощённым фигурам. Изменение выбора на одной вкладке не меняет настройки и отметку другой. При обновлении с 1.1.29 прежний общий выбор становится начальным значением для обеих вкладок. По умолчанию сохранена свободная раскладка по полному контуру; разрешённые повороты остаются прежними. Зазор и максимальная длина страницы по-прежнему общие для обеих раскладок.

| Плотность | Занятая область при поиске |
| --- | --- |
| Прямоугольники | Полные габариты каждой детали; дополнительное чтение контурных полос пропускается. |
| Упрощённые фигуры | Наружная ступенчатая оболочка из полос по 20 мм, сетка по ширине до 10 мм. Минимумы и максимумы расширяют занятое место, не подрезая исходник. |
| Полный контур | Консервативные профили прямых и Безье с сеткой до 2 мм и дополнительным поиском перестановок. |

Геометрия экспорта остаётся исходной: упрощается только представление занятой области для поиска. Прорезные язычки, надсечки и подписи учитываются; при недоступном контуре применяется безопасный прямоугольный габарит.

| Группировка | Порядок укладки |
| --- | --- |
| Свободно | Все детали заказа уплотняются независимо. |
| Парами | Перед и спина каждого экземпляра комплекта образуют неразделяемую пару. Сначала укладываются все пары заказа, затем рукава и горловины: сначала в свободную длину снизу последнего листа, потом на новые листы. |
| Комплектом | Все имеющиеся детали одного экземпляра комплекта образуют один блок на одном листе. Сначала подбирается их взаимное положение, затем блоки уплотняются между собой. |

Блоки не поворачиваются целиком: разрешённые повороты отдельных деталей подбираются внутри них. Разные размеры и повторы игроков не смешиваются в одной паре/комплекте. Группировка может увеличить расход материала. Если целая пара или комплект не помещается на один лист, операция сообщает номер комплекта: увеличьте длину/ширину либо выберите свободную раскладку. Допечатка одной детали всегда использует свободный режим. Алгоритмы эвристические и не гарантируют абсолютный минимум длины.

## Длина страниц и заполнение свободных мест

Настройка **«Макс. длина страницы, м»** применяется к печати и резке, по умолчанию **4 м**. Допускается от 0,5 до 45 м. Настройка сохраняется на этом ПК. Раскладка создаётся на нескольких страницах текущего CDR; ни одна не превышает заданную длину. **«Ширина печати, мм»** задаёт ширину бумаги для печати, **«Ширина ткани для резки, мм»** в разделе резки — ширину ткани независимо от бумаги. Оба поля принимают 300–4000 мм и запоминаются отдельно. При первом открытии старого черновика прежняя ширина переносится в оба поля. Зазор и ограничение длины остаются общими. Один комплект может быть распределён между страницами; имена групп и подписи деталей позволяют найти его части. Обзорная страница этапа 1 остаётся отдельной сеткой размеров.

Для печати проверяется профиль **печатного контейнера с уже построенным припуском +6 мм**, включая обводку. Видимые подписи, номера, имена и оставленные красные рамки за пределами контейнера дополнительно резервируют свои габариты; скрытые вспомогательные рамки сохраняются в группе, но не занимают печатное место. Растры внутри PowerClip ограничены контейнером. Поворот рукавов и горловины на 90° применяется вместе с рисунком и подписями; перед и спина сохраняют ориентацию. Для резки проверяются профили исходной геометрии с поворотом только на 180° или без него. Поиск возвращается к свободным местам на предыдущих страницах, прежде чем создать новую. Сравниваются три порядка первоначальной укладки: выбирается вариант с меньшим числом страниц, затем с меньшей общей длиной и более ровным заполнением по ширине.

Печатные кривые читаются один раз для каждой детали размера и масштаба. Прямые и Безье разбиваются на консервативные полосы с габаритами до 1 мм; поиск использует столбцы шириной до 2 мм. Это позволяет сближать фигурные края без пересечения печатных областей. При недоступном или незамкнутом контуре используется прямоугольник печатных габаритов, причина записывается в журнал. Геометрия и разрешение рисунков сохраняются; печатная раскладка не растрируется. Фактические печатные габариты после поворота сверяются с расчётом перед размещением.

После первичной укладки **печати и резки** выполняется дополнительный поиск перестановок: деталь, занимающую середину неполного ряда, можно отложить в конец или вставить раньше/позже в порядке укладки, чтобы остальные детали заполнили её прежнее место. Для страниц до 24 деталей перебираются все позиции вставки и используется более частый поиск по ширине; для страниц до 80 деталей рассматриваются отложенные детали и несколько позиций вставки. Принимаются только полностью размещённые перестановки с меньшей высотой либо более ровным нижним краем при той же высоте. Оптимизация проводится до двух проходов, начиная со страниц с большим количеством пустого места.

Освободившиеся промежутки заполняются деталями с последующих листов без увеличения длины прежних страниц; освободившиеся листы удаляются из результата, оставшиеся детали уплотняются. Дополнительному поиску отведено около **8 секунд сверх первичной укладки**, с проверкой времени во время поиска положений. На многолистовой раскладке часть этого времени оставляется для переноса между листами. Исходный результат сохраняется, если дополнительный поиск не улучшил число листов, общую длину или ровность нижнего края. Все расчёты выполняются по уже считанным профилям, без дополнительных вызовов Corel. Детали последнего ряда по возможности выравниваются к общему нижнему краю без увеличения страницы и пересечений. Алгоритм эвристический и не гарантирует абсолютный минимум материала.

Страницы получают номера `1/N`, `2/N` и так далее. После генерации открывается первая страница. Общая длина и число страниц показаны в докере. **«Сохранить страницу резки в отдельный CDR» сохраняет только активную страницу**: при многостраничной раскладке переключайтесь между страницами и выбирайте отдельные имена файлов.

## Экспорт листов печати

После этапа 2 откройте нужный лист печати и в разделе **«Экспорт печати»** выберите папку. Кнопка **«Экспортировать активный лист печати в PDF»** создаёт отдельный PDF только этой страницы: сохраняются её полная ширина, длина и масштаб **1:1**, независимо от выделенных объектов. Обзорная страница размеров и страницы резки не экспортируются этой кнопкой. Папка и качество сохраняются в черновике на этом ПК. Имена файлов содержат имя CDR, номер страницы и время; прежние PDF не перезаписываются.

По умолчанию используется компактный режим: цветные и серые изображения уменьшаются до **150 DPI**, JPEG-сжатие с качеством **95%**. Детальный режим повышает предел до **300 DPI**. Исходники с меньшим разрешением не увеличиваются искусственно. Надписи выводятся кривыми и вместе с остальной векторной графикой сохраняют чёткость независимо от DPI. Весь многометровый лист не превращается в единый растр. PDF 1.7 сохраняет прозрачность, текстовые и векторные потоки сжимаются. Вылеты PDF, метки обрезки и служебная информация отключены: припуск +6 мм уже включён в печатные детали. Исходные цветовые модели сохраняются режимом `pdfNative`; устаревший переключатель `UseColorProfile`, который Corel 2026 отклоняет с `E_NOTIMPL`, не используется. Профиль материала и зеркалирование задавайте в программе печати. При ошибке настройки экспорта сообщение и журнал показывают имя параметра PDF; восстанавливаются только параметры, которые удалось изменить.

Экспорт в масштабе 1:1 ограничен страницей до **5,08 м** по каждой стороне, чтобы исключить автоматическое уменьшение крупного макета при выводе Corel в PDF. Стандартные листы длиной 4 м подходят. Для нескольких листов откройте каждый по очереди и повторите экспорт; в результате показаны физические размеры, размер файла и путь. PDF сначала создаётся в системной временной папке, затем копируется в папку печати с расширением `.partial` и получает окончательное имя `.pdf` только после завершения копирования. Настройки PDF и единицы рабочего CDR восстанавливаются после операции; геометрия и исходный CDR не меняются.

## Съёмный язычок с прорезным размером для лазерной резки

Галочка **«Съёмный язычок на каждой детали»** добавляет П-образный выступ непосредственно к нижнему краю детали. Между язычком и деталью остаются два непрорезанных промежутка на исходной линии; дополнительных ножек нет. Настройки в миллиметрах: ширина по умолчанию **24**, высота **12** (минимум 12), длина каждого мостика **2**, высота буквы **8**. Если включено **«Прорезать размер внутри язычка»**, высота буквы должна быть хотя бы на 2 мм меньше высоты язычка. Длинная метка автоматически увеличивает ширину; высота надписи сохраняется.

Можно снять галочку прорезной надписи: площадка останется цельной, размер определяется положением язычка. В этом режиме буква не влияет на ширину и не добавляет внутренних надрезов. Пресет **«30×20 мм · мостики 4 мм»** выставляет площадку 30×20 мм, два мостика по 4 мм и высоту буквы 8 мм, сохраняя выбранный режим надписи. Это кандидат для пробы, а не подтверждённая конструкция для любой ткани. Старые настройки автоматически не заменяются.

Надпись — собственные однолинейные чертёжные векторные знаки с разрывами замкнутых частей. Это не системный шрифт и не заявление о соответствии ГОСТ. Гравировка и двойные контуры букв не используются. Поддерживаются латинские буквы, цифры, `+`, `-`, `/`, `.`; М/С/Х/Л приводятся к M/S/X/L. Из `фо140` или `128 рост` получается `140` или `128`.

**Положение по размеру:** левый угол крепления первого язычка находится в 10 мм по горизонтали от левого начала прямого нижнего края в ориентации подготовленного шаблона. Следующие размеры получают отступы 30, 50, 70 мм и далее. Первый отступ и шаг настраиваются. Порядок определяется площадью исходной `silhouette` переда с учётом масштаба, от меньшей к большей, **только среди уникальных размеров отмеченных игроков текущего запуска резки**. При одинаковой площади применяется порядок названий. Для S и M это 10 и 30 мм; если выбран только M, он получает 10 мм. Ранее подготовленные или добавленные в каталог невыбранные размеры не влияют на смещения. При изменении выбранного набора смещения пересчитываются; все детали одного размера в текущем запуске получают одинаковый отступ. Подготовлены должны быть только выбранные размеры.

Место крепления должно лежать на свободном прямом нижнем крае в рассчитанной позиции. Поддерживаются наклонные края, прямые Безье и сонаправленные сегменты на одной линии с допуском 0,05 мм. Направление наружу проверяется по исходному контуру. Начало края вычисляется по пригодным нижним прямым; соосные участки, разделённые надсечками, используют одно левое начало. У трапециевидного рукава верхний левый угол общего габарита не задаёт отступ язычка. Проверяются реальные отрезки остальных линий и близкая к Безье ломаная с допуском, а не весь прямоугольник наклонной линии. Это исключает ложное пересечение с далёким боковым краем. Остаются проверки всех надсечек; причины отказа каждого прямого участка записываются в журнал. Автоматического смещения в другую позицию нет: если язычок не помещается, сообщение показывает размер, деталь и отступ; измените отступ/шаг или отключите язычки. Это сохраняет идентификацию размера по положению. На коротких деталях большие отступы могут не помещаться.

На копии `silhouette` точно вырезаются только два интервала мостиков, включая деление Безье и стыки сегментов. Добавляются П-образный контур и линии символов. Исходный CDR и обзорная страница не меняются. Весь габарит язычка учитывается в раскладке; поворот резки только 0°/180°. Повторяющиеся детали копируются из уже подготовленного образца размера.

### Лист пробной резки язычков

Кнопка **«Лист язычков для пробной резки»** создаёт страницу резки и отдельную страницу **«Памятка · проба язычков»** без таблицы игроков и лекал. Сравниваются пары с буквой M высотой 8 мм и без буквы: исходные 24×12 мм с мостиками по 2 мм, 30×20 и 40×25 мм с мостиками по 3 и 4 мм. Также добавляются текущие размеры и примеры S, XS, XL, XXL, 116, 128, 152 на площадке 30×20 мм с мостиками 4 мм. Совпадающие варианты не дублируются; при стандартных настройках получается **17 образцов**.

Каждый образец — прямоугольный купон с язычком. Мелких прорезных кодов на купонах нет. Памятка показывает копии образцов в той же сетке, координаты **A1, B1…**, реальные размеры, мостики и режим надписи. Сохраняйте расположение купонов при разборе, чтобы сопоставить результат с памяткой. Активной после создания остаётся страница резки; её можно сохранить отдельным CDR или экспортировать в DXF. Памятка имеет другое имя страницы и не проходит проверку страницы резки. Сохраните весь рабочий CDR, чтобы оставить обе страницы. Сравнивайте варианты на своей ткани при одинаковом режиме лазера.

Кнопка «Сохранить страницу резки в отдельный CDR…» сохраняет только открытую страницу резки как копию. Рабочий документ сохраняет прежний путь. Версия CDR берётся из настройки версии сохранения. Выберите отдельное имя файла; нельзя перезаписать CDR, который сейчас открыт. Для старого макета без групп `VT_SPORT_CUT_*` удалите его слой размера и повторите этап 1, чтобы восстановить только этот размер.

### Экспорт листов резки в DXF

Откройте нужную страницу резки после генерации, выберите **«Папка резки…»** и нажмите **«Экспортировать активный лист резки в DXF»**. Папка хранится в черновике отдельно от папки печати. Каждый экспорт создаёт новый файл с именем документа, номером страницы и временем; существующие DXF не перезаписываются. Для нескольких страниц откройте каждую по очереди и повторите экспорт. Лист пробной резки язычков тоже подходит.

Используется штатный векторный фильтр Corel `ExportEx` с диапазоном `cdrCurrentPage`, **DXF AutoCAD 2000**, единицы **миллиметры**, масштаб **1:1**. Выделение объектов не ограничивает экспорт страницы. Контуры, открытые надсечки, язычки и прорезные буквы остаются векторными; растрирование, дополнительное упрощение кривых и подгонка под лист не выполняются. Размеры страницы показаны после экспорта; её рамка не добавляется как линия резки. Печатные растры и текстовые объекты на странице резки отклоняются перед экспортом. Параметры фильтра задаются через [API экспорта Corel](https://community.coreldraw.com/sdk/w/guide/215/8-7-working-with-import-filters-and-export-filters).

DXF сначала создаётся во временной папке. После проверки начала и завершения файла он копируется в папку резки под временным расширением `.partial` и получает имя `.dxf` только после завершения копирования. Единицы и состояние изменения рабочего документа восстанавливаются; его геометрия и путь остаются прежними. Совместимость DXF AutoCAD 2000 и отображение кривых нужно подтвердить в вашей программе лазерной резки при первом использовании.

Исходный CDR модели остаётся открытым в отдельной вкладке, а рабочий документ остаётся активным. Повторные операции используют уже открытую модель. Это исключает автозакрытие исходного документа, пока Corel и плагин ещё держат ссылки на его объекты.

Перед созданием обзорной страницы проверяются группы и имена деталей всех выбранных размеров. При ошибке в одном слое выводится его имя и список недостающих деталей; импорт рисунков ещё не начинается. Перенос между CDR ожидает освобождения буфера обмена и повторяет временно неудавшееся копирование до трёх попыток. Если буфер остаётся занят, сообщение показывает размер и, когда Windows позволяет определить его, приложение, удерживающее буфер.

Во время ожидания обрабатываются входящие синхронные сообщения Windows: это позволяет Corel передать отложенные данные буфера по запросу системной службы. Мышь, клавиатура, таймеры и отложенные команды докера остаются в очереди до завершения операции. Службы Windows и настройки истории буфера не меняются.

На обзорной странице для каждой детали создаётся группа `VT_SPORT_ART_FRONT`, `VT_SPORT_ART_BACK`, `VT_SPORT_ART_LEFT_SLEEVE`, `VT_SPORT_ART_RIGHT_SLEEVE` или `VT_SPORT_ART_NECK`, даже если её рисунок не выбран. В эту группу можно добавить графику до второго этапа. Стороны груди теперь соответствуют именам боксов без зеркального обмена: `FRONT_LEFT` — левый бокс на странице, `FRONT_RIGHT` — правый.

Крестик возле поля рисунка очищает выбранную деталь для всех размеров на текущей обзорной странице. Пустое поле правого рукава оставляет его без печатного рисунка; рисунок левого рукава больше не подставляется автоматически.

### Редактируемые рисунки размеров

В разделе рисунков режим **«Объекты Corel · редактируемые»** включён по умолчанию. Выделите графику нужной детали и нажмите **«Взять выделение из Corel»**. Плагин сохраняет только выбранные объекты отдельным CDR текущей версии в своей папке `sport-patterns`; исходный CDR не переименовывается и не перезаписывается. Кривые, текст, заливки, группы и PowerClip сохраняют структуру. Уже встроенные растры остаются растрами.

Этап 1 создаёт отдельную копию группы рисунка для каждого размера. Внутри неё можно двигать логотипы, править линии и текст: используйте Ctrl+щелчок для выбора объекта внутри группы. Внешняя именованная группа рисунка должна оставаться на слое соответствующего размера. Этап 2 копирует эту группу и помещает её в PowerClip печатного контура; правки одного размера не передаются другим. Повтор этапа 1 добавляет только недостающие размеры и сохраняет существующие ручные правки.

Кнопка **«Обновить в макетах»** у детали заменяет только её рисунок в уже подготовленных размерах игроков с галочкой «Печатать». Лекала, образцы имён и номеров, подписи и рисунки остальных деталей сохраняются. Ручные правки заменяемой группы сбрасываются; операция отменяется одним Ctrl+Z. После обновления открывается обзорная страница с выбранными новыми группами. Если выбранный размер ещё не подготовлен, для него нужен этап 1.

Для перехода со старого PNG возьмите рисунок заново из исходного вектора и нажмите **«Обновить в макетах»**. Автоматической трассировки PNG нет. Можно выбирать CDR с рисунком или прежние PNG/JPG/TIFF/BMP через файловый диалог. Каждый файл используется как рисунок одной детали; для переноса части большого CDR используйте выделение в Corel.

### Память при растровом захвате рисунка

Режим **«PNG · снимок 300 DPI»** сохраняет прежний растровый захват. Его предел выбирается в разделе рисунков: **100 / 150 / 200 / 250 Мп**, по умолчанию **150 Мп**, и сохраняется в черновике вместе с режимом захвата. Отдельный предел стороны — 20 000 пикселей. Если выделение превышает предел, захват останавливается; разрешение автоматически не снижается. Например, рисунок 642,09×865,49 мм занимает около 77,53 Мп при 300 DPI и проходит новый стандартный предел. Для копирования объектов в CDR эти пределы не применяются; поле лимита показывается только в режиме PNG.

До создания временной копии и повторно перед её растрированием проверяются свободная физическая память и доступный объём выделения памяти процессу по `GlobalMemoryStatusEx`. Используется меньшее из двух значений ([Microsoft: MEMORYSTATUSEX](https://learn.microsoft.com/en-us/windows/win32/api/sysinfoapi/ns-sysinfoapi-memorystatusex)). Бюджет операции — 24 байта на пиксель плюс 256 МиБ; отдельно оставляется резерв не меньше 1 ГиБ или 1/32 установленной ОЗУ. Оценка учитывает несколько рабочих буферов Corel, BGRA, WPF и PNG. При отказе сообщение показывает оценку требуемой и доступной памяти; значения записываются в журнал. Проверка отражает состояние памяти в момент запроса и не резервирует её у Windows.

Ориентировочный запас свободной памяти по этой проверке для ПК с ОЗУ до 32 ГиБ:

| Размер рисунка | Свободная память с резервом |
| --- | --- |
| 100 Мп | 3,5 ГиБ |
| 150 Мп | 4,6 ГиБ |
| 200 Мп | 5,7 ГиБ |
| 250 Мп | 6,8 ГиБ |

Это бюджет проверки, а не подтверждённые измерениями максимумы. Даже достаточная ОЗУ не гарантирует отсутствие сбоев Corel: сложные эффекты, исходные растры и временная копия документа могут потребовать больше памяти. Размер сжатого PNG на диске не отражает расход ОЗУ. Предел относится только к одному захвату рисунка; суммарный расход обзорной страницы и комплектов зависит от количества деталей и копий. Экспорт всей страницы в PDF использует отдельный путь без растрирования всего рулона.

### Выбор строк и отдельное окно игроков

Флажок «Печатать» в таблице сохраняется в черновике; по умолчанию все строки включены. «Печатать всех» / «Снять все» работают со всем списком. Печать и резка учитывают только отмеченные строки. Кнопка большого окна переносит тот же редактор в изменяемое окно с вставкой диапазонов, назначением размеров и флажками; данные остаются общими с докером. ↗ в строке — явная допечатка одной детали, независимо от массового выбора.
