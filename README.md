# CorelDRAW workspace macros

Рабочий набор макросов и докер-панель для автоматизации повторяющихся операций в CorelDRAW.

## 1.1.98 · скорость полупрозрачности и почти белого

Предпросмотр удаления полупрозрачности, подбеливания и обеих подсветок работает с пикселями в памяти, без повторного сохранения и чтения PNG при каждом движении ползунка. Точный фрагмент сохраняет исходные пиксели, обзор использует выбранное разрешение. Полная обработка выполняется в исходном разрешении по «Применить».

Рабочие PNG сохраняются без затратного подбора фильтров и сжатия; большие файлы исходных каналов используют совместимые несжатые DEFLATE-блоки. Временные файлы больше, зато меньше времени уходит на подготовку, сохранение и чтение. Формат PNG, пиксели, альфа, DPI и физические размеры проверяются; исходные RGB/CMYK/Grayscale каналы сохраняются. Подбеливание родных каналов больше не выделяет полный дополнительный RGB-буфер и маску.

На одном синтетическом RGB 5201×8029 (41,76 Мп) подготовка и полная обработка «порог + подбелить» сократились с **23,59 до 6,53 с** (примерно в 3,6 раза); захват и вставка Corel в этот замер не входят. На обзоре 2200×1600 прежнее файловое подбеливание заняло 776 мс, обработка в памяти — 28 мс, объединённая подсветка — 37 мс. Это замеры на данном ПК, скорость на других ПК зависит от процессора и диска. Проверки эквивалентности фильтров и декодирования PNG пройдены; живой Corel при проверке не запускался.

## 1.1.97 · проверка обновлений через сетевой помощник

Индикатор обновлений получает сведения GitHub через установленный сетевой помощник, как индикатор Replicate. Прямое соединение из процесса Corel больше не используется: Windows на некоторых ПК запрещает ему доступ к сокету. Сохраняются кэш, ограничение времени, проверка готовности ZIP и прежние состояния точки. Проверка читает только сведения о выпуске; правила защиты Windows не меняются, пакет автоматически не скачивается и установка не запускается. Для нового действия нужна версия помощника 1.1.97, входящая в полный пакет обновления.

## 1.1.96 · индикатор обновлений

В заголовке рядом с Replicate и принтером этикеток добавлена третья мини-точка. **Зелёная** — установлена актуальная версия; **красная мигающая** — доступен новый стабильный выпуск с готовым ZIP; **серая** — состояние пока не удалось проверить. Подсказка при наведении показывает версии и время проверки. Нажатие на красную точку открывает обычное обновление с подтверждением, на зелёную или серую — повторяет проверку.

Проверка выполняется в фоне при открытии докера и затем раз в 15 минут, без скачивания пакета и автоматической установки. Мигание при скрытом докере останавливается. Если новый выпуск уже найден, временная потеря сети сохраняет красный сигнал и показывает пояснение в подсказке.

## 1.1.95 · восстановление обработки растра и поля печатного PDF

- Готовый результат после неудачной вставки больше не блокирует работу без выхода. Рядом с предпросмотром доступны **«Вставить рядом»**, **«PNG ↗»** и **«Отложить»**. После перезапуска для сохранённого результата с данными размещения используется безопасная вставка рядом, без изменения исходника и повторной обработки. Нужно открыть исходные документ и страницу.
- **«Отложить»** сохраняет результат в локальном списке до 50 записей и освобождает инструменты для нового выделения. PNG и данные цветовых каналов сохраняются; результат можно открыть или вернуть из списка.
- Поиск исходных объектов при замене и сдвиге дополнен обходом рабочего стола, слоёв, вложенных групп и PowerClip исходной страницы. Проверка реального изменения объектов сохранена. Журнал теперь различает недоступный объект, смену имени, типа и геометрии.
- Файловая обработка большого растра использует прочитанные цветовые каналы без дополнительной полной копии. Для RGB 5201×8029 это убирает около 159 МиБ лишних данных. Добавлены тайминги захвата, чтения, фильтра, сохранения и применения каналов.
- PDF **выделения** для очередей DTF/UV/SUB получает по **2 мм прозрачного поля с каждой стороны**. Рисунок сохраняет масштаб 1:1, страница увеличивается на 4 мм по ширине и высоте. Экспорт активной страницы, страницы раскладки формы и фотовывод сохраняют свои размеры. Контроль границ включает обводку, масштаб и все четыре поля.

По присланному журналу большой растр завершил обработку и остановился на проверке исходника при вставке; подтверждения зависания фильтра или нехватки памяти нет. Причина подрезания на конкретном принтере пока не подтверждена: защитные поля и новая диагностика требуют проверки на том же задании. Сборка и автономные проверки пройдены; Corel и принтер при проверке этого выпуска не запускались.

## 1.1.94 · выбор областей фона и журнал развёрток

- В «Удалить фон» выберите **«Волшебная палочка»** и щёлкайте по внутренним областям исходника. Каждый щелчок добавляет связанную область своего цвета; допуск задаётся ползунком. Доступны отмена последней точки и сброс. **«Край + области»** одновременно убирает внешний фон и выбранные участки внутри. Связность считается по исходным пикселям, даже при уменьшенном обзоре; окончательная обработка сохраняет родные каналы RGB/CMYK/серого поддерживаемого растра.
- Обрезка учитывает прозрачный фон однобитового изображения, заданный через «Нет заливки», и сохраняет модель 1 bit. Тонкие элементы проверяются точно, без грубой сетки; большие пустые поля могут обрабатываться медленнее обычных RGB-растров.
- Развёртка привязана к документу и странице, где выбран исходник. Результат получает отдельный видимый печатаемый слой и заданный размер в мм. Если исходная страница не активна, PNG сохраняется для повторной вставки. После вставки Corel показывает новый растр.
- **«Последние результаты»** хранит список десяти готовых PNG с миниатюрами, моделью, временем и состоянием вставки. **«Вставить ещё»** использует готовый файл без обращения к Replicate. После перезапуска журнал восстанавливается, пока локальные временные PNG существуют. Старые результаты без данных исходной страницы можно открыть как PNG и импортировать вручную.
- При смене модели готовый анализ используется повторно, если пиксели исходника, деталь, уточнение и целевой размер совпадают. Изображение для новой модели создаётся новым запросом. Анализ и кадрирование рукава не оплачиваются повторно.
- **«Сводка цветов выделения»** перенесена с главной вкладки в **«Цветопробу»**. Формулы и отдельный текст с назначением заливок/контуров размещаются под выделением.

Автономные проверки и сборка пройдены. Новые режимы ещё не проверены в живом Corel и платной генерацией.

## 1.1.93 · экспресс-аудит растра и выбор модели развёртки

- В окне коррекции сверху расположен **«Экспресс-аудит»**: независимая подсветка полупрозрачных и почти белых пикселей. Допуск почти белого задаётся ползунком, по умолчанию **6**; отметка — ярко-розовая с прозрачностью 50%, цвет можно выбрать. Точный белый и полностью прозрачные пиксели не отмечаются. **«Подбелить»** — отдельная выключенная по умолчанию операция: подходящие оттенки становятся чистым белым с сохранением alpha. Диагностические отметки не попадают в обработанный файл. Сглаживание, величина обводки и цвет собраны в одну строку.
- Локальная коррекция одного исходного 8-битного растра читает и записывает исходные каналы **RGB, CMYK или Grayscale** без повторного RGB-растрирования и обратного пересчёта печатных каналов. Порог прозрачности меняет alpha, обводка сохраняет существующие пиксели, сглаживание обрабатывает каналы в исходной модели. Белый RGB сохраняет `255/255/255`, белый CMYK — `0/0/0/0`; подбеливание использует соответствующий чистый белый исходной модели. Обрезка по-прежнему выполняется нативно в Corel. Для повёрнутых, зеркальных, наклонённых растров, незавершённой обрезки и объектных эффектов показано требование подготовить отдельную копию: модель не подменяется молча. Составное выделение растеризуется в RGB, поскольку общей модели исходного растра у него нет. Экранный CMYK-предпросмотр приблизительный; сохранённые печатные каналы не берутся из него. Сохранение отдельного исходного ICC-профиля этим изменением не заявляется.
- **«Результат обработки»** перенесён с главной панели в **«Настройки → Обработка растра»**. Прежний выбор размещения сохраняется. Сводка цветов создаёт формулы построчно без заголовка; роли заливок/контуров и пояснения находятся ниже отдельным текстом 14 пт, который можно удалить независимо.
- В развёртке формы добавлен явный выбор **Nano Banana 2**, **Nano Banana Pro**, **Seedream 4.5** и прежней FLUX.2 Pro. Новое задание использует выбранную модель, продолжение — модель, сохранённую в задании. Старые задания остаются на FLUX. После E005 нет автоматической смены модели или повторной платной отправки. Выбор другой модели не гарантирует отсутствие отказа её фильтра. Для моделей заранее проверяются поддерживаемое соотношение сторон и входные параметры.

Нативная проверка в отдельном синтетическом документе Corel пройдена для RGB, CMYK и Grayscale: порог alpha, обводка, подбеливание, точный белый и полностью непрозрачный результат. Исходные данные и рабочий документ не изменились. Платные генерации новыми моделями в этой проверке не запускались.

## 1.1.92 · состав кадров, история замеров и отзывчивость докера

- Кадры карточки создаются прямым экспортом исходного выделения в PNG. Убрано временное дублирование, при котором Corel мог изменить порядок объектов и закрыть надписи изображением изделия. Исправление проверено внутри Corel на локальной копии проблемного макета: надписи сохранены, исходные объекты и файл не изменены. **Ранее сохранённые неполные кадры нужно переснять кнопкой ↻ и затем обновить фотографии карточки.** Они не изменяются автоматически при публикации. Чтение растровых пикселей также проверяет полноту цветового и альфа-каналов и сообщает о неполном изображении.
- В «Экспериментальное → Рулетка» под результатом добавлена история успешных измерений: кривая, длина или меньший участок и больший участок в миллиметрах. История накапливается в текущем сеансе панели; **«Очистить историю»** удаляет строки вручную. Документ и узлы указаны в подсказке строки.
- Автоматическая проверка CDR и запись связей заказов в сетевую папку вынесены из интерфейса в общую фоновую очередь. Повторные одинаковые задания объединяются; файловые операции выполняются последовательно. Диагностика обоих докеров различает экземпляры, потоки, задержку очереди и текущую синхронную операцию. Найденный путь ожидания NAS устранён; связь с конкретным зависанием на другом ПК требует повторной проверки.
- Отказ модели развёртки **E005 / flagged as sensitive** показывается отдельно от сетевой ошибки. Сохраняются исходник и готовые этапы; предложение автоматически продолжить отклонённый запрос убрано, в том числе после перезапуска. Готовый PNG по-прежнему можно повторно вставить без новой генерации. Фильтры сервиса и параметры модели не изменены.

## 1.1.91 · вставка готового апскейла и печатные формулы

- Исправлена излишне строгая проверка исходной страницы при вставке готового результата: разные программные объекты одной страницы больше не вызывают отказ только из-за различия обёрток Corel. Для вставки рядом допускается повторное получение того же сохранённого CDR; этот режим не читает, не удаляет и не перемещает исходные объекты. Замена и перенос исходника по-прежнему требуют точного документа и проверяют наличие исходных объектов на активной странице. В ошибке и журнале теперь различаются смена файла, страницы и потока интерфейса. Готовый PNG из 1.1.90 можно повторно вставить без новой обработки: откройте исходный CDR и страницу, выберите «Результат рядом с исходником» и нажмите «Повторить вставку · бесплатно».
- На вкладке цветопробы над предпросмотром добавлена видимая галочка **«Формулы справа на листе»**, включённая по умолчанию. Она управляет печатной легендой и предпросмотром обычных таблиц и серий. При отключении не резервируется боковая полоса и дополнительная высота легенды; номера и каталог рецептур внутри CDR сохраняются. Настройка действует при создании новой таблицы. Ранее созданные страницы автоматически не дополняются.

Изолированные проверки вставки, геометрии легенды и интерфейса прошли. Повторная вставка на реальном ПК с ошибкой ещё требует проверки.

## 1.1.90 · вставка результата, сводка цветов и выбор палитр

- На главной вкладке добавлен выбор вставки: **«Заменить исходник»**, **«На место, исходник вправо»**, **«Результат рядом с исходником»**. Выбор сохраняется на компьютере. Он применяется к коррекции, обводке, удалению фона, сглаживанию и апскейлу главной вкладки. Подсветка прозрачности всегда создаёт отдельную диагностическую копию. При вставке учитываются исходные размеры, срез и расширение обводки; исходные объекты проверяются перед заменой или перемещением. Готовый PNG можно повторно вставить после ошибки, без повторной обработки.
- **«Сводка цветов»** создаёт многострочный текст 14 пт под выделением: левый край совпадает с выделением, отступ вниз — 5 мм. Повторяющиеся векторные цвета объединяются; сохраняются модели и названия плашечных цветов. Для растра выводятся до восьми основных групп оттенков с пометкой о приблизительности. Сложные заливки и эффекты сопровождаются пояснением о неполной сводке.
- В окне Pantone установленные палитры **Solid Coated** выбираются галочками. Можно искать в одной или нескольких версиях; у каждого результата указан источник. Первой предлагается новая версия, ручной выбор XML/CPL остаётся в параметрах. Полный путь к палитре виден при наведении на её строку. На этом ПК файлы находятся в `C:\Program Files\Corel\CorelDRAW Graphics Suite\27\Color\Palettes\Spot\PANTONE\`; путь зависит от установки Corel.

Сборка и изолированные проверки геометрии, интерфейса и протокола работы с Corel пройдены. Новые операции внутри Corel пока требуют проверки на реальном макете.

## 1.1.89 · легенда цветопробы справа

- В сетках цветопробы справа печатается легенда в две колонки: `1 CxxMxxYxxKxx  2 CxxMxxYxxKxx`, затем `3 …  4 …`. Рецептуры точно соответствуют номерам под плашками и сохранённому каталогу CDR; в серии сохраняется сквозная нумерация. Для RGB показываются компоненты RGB.
- Легенда также видна в предпросмотре. Размеры и значения плашек сохраняются; справа требуется полоса 70 мм, длинная легенда увеличивает высоту листа. При недостаточной ширине показано требование до изменения документа. Изменение применяется к новым таблицам.
- Проверены обычные и составные сетки, номера и рецептуры каталога, таблицы на 900 и 3844 образца, границы листа. Проверка легенды добавлена в сборку релиза.

## 1.1.88 · совмещение выделения при отправке на печать

- Исправлено размещение выделения на временной странице PDF для кнопок SUB, DTF и UV. После изменения размера страницы координаты скопированных объектов измеряются заново: учитывается сдвиг начала координат и содержимого, который может выполнить Corel. Это устраняет отказ «Не удалось совместить выделение с границами временной страницы» при правильных исходных размерах.
- Габариты и положение проверяются после размещения с точностью 0,02 мм. Сообщение о несовпадении теперь содержит ожидаемые и фактические координаты в миллиметрах для диагностики. Выделенные объекты, включая расположенные за пределами исходного листа, переносятся целиком.

## 1.1.87 · клиентские номера и точное повторение цвета

- Под каждой плашкой печатается обычный сквозной номер, в шапке — код таблицы вида **CP-AB12CD34**. Клиент выбирает номер; техническая легенда R/C/Q убрана. Под подписи выделены отдельные полосы 3,5 мм, включая составные микроряды: цветные зоны сохраняют исходные размеры и остаются без текста.
- Рецепты всех номеров — точная модель и компоненты RGB/CMYK на момент создания — сохраняются внутри CDR. Кнопка **«По номеру»** открывает таблицы этого файла и позволяет найти состав, сделать его эталоном либо создать отдельную плашку 20×20 мм. Сохраните CDR после создания таблицы. В прежних таблицах без каталога нужный цвет можно взять через выделение.
- Экранный цвет преобразуется через профили документа в sRGB, включая цвета Pantone. Печатные значения RGB/CMYK не пересчитываются ради предпросмотра. ## 1.1.66 · раскладка пресса по согласованным образцам

- Исправлено чтение миниатюр принтов: удалён `IgnoreImageCache` при `StreamSource`, вызывавший в WPF `ArgumentNullException` с сообщением «Ключ не может быть неопределенным». Прочие детали сохраняют свободный расчёт для случаев, не покрытых образцами.

В свободном режиме прежняя настройка ширины по-прежнему ограничивает все листы. Четыре поля сохраняются отдельно.

Общие листы рукавов идут первыми, затем пары корпусов и крупные комплекты. Предпросмотр показывает количество малых и крупных комплектов, собранных по образцам. Проверяются принадлежность рукавов строкам, стороны колонок, физический размер плиты и сохранность всех деталей. Варианты ориентации и экономии не получают приоритет над применимостью образца.

## 1.1.65 · отдельные детали в боковых полосах рулона

- После первичной сборки листов пресса добавлен второй этап: поиск свободных полос на полной ширине рулона. Раньше на этом этапе двигались только целые листы, поэтому широкие блоки могли оставить незаполненную полосу около 40 см, хотя отдельные рукава туда помещались.
- Для фактической ширины остатка пробуются узкие отрезные листы из деталей заказа: сначала из листов с мелкими деталями, затем из рукавов/горловин, прикреплённых к основным листам, и из подходящих по ширине отдельных корпусов. Детали переносятся между кандидатами без дублирования. У исходного листа после переноса уменьшаются границы; у узких листов сохраняются поля, ограничения пресса, разрешённые повороты и правила сторон.
- Разные размеры могут находиться рядом на рулоне **только в разных отрезных прямоугольниках**; внутри каждого листа размер один. Все детали остаются внутри своих полей, количество и уникальность деталей проверяются при сборке каждого варианта. Ошибка дополнительного варианта не отменяет уже рассчитанную исходную раскладку.
- При выборе варианта сначала сравнивается суммарная длина рулона, затем число отрезных листов при равной длине. Поэтому небольшое увеличение числа листов допускается, когда узкие боковые блоки сокращают расход бумаги. Приоритет комплекта и пар остаётся в первичной сборке; отдельные детали могут переходить в боковые блоки ради экономии.

Сборка выполнена; новую компоновку на пользовательском файле внутри CorelDRAW ещё не проверяли.

## 1.1.64 · миниатюры рисунков и листы пресса

- Во вкладке «Рисунки» рядом с выбором принта каждой детали показана растровая миниатюра 68×68. Нажатие открывает увеличенный просмотр; прозрачный и белый рисунок виден на клетчатом фоне. Полный путь файла доступен в подсказке поля.
- Для выделения, сохранённого редактируемыми объектами CDR, дополнительно сохраняется PNG не более 640 пикселей по длинной стороне. У готовых CDR читается встроенная миниатюра, у PNG/JPEG/TIFF/BMP — уменьшенный просмотр изображения. Если в старом CDR нет встроенного превью, подсказка предлагает взять выделение из Corel. Исходные рисунки сохраняют свой формат.
- Загрузка файлов и декодирование выполняются в фоне с ограничением параллельных чтений. При смене файла, очистке или переключении проекта прежнее изображение убирается сразу; запоздавший результат не подменяет текущий принт. Миниатюры восстанавливаются из путей, сохранённых в CDR проекта.
- Для листового пресса добавлены отдельные варианты группировки: **«Комплект → пара → корпус с рукавами»**, **«Перед/спина + общие рукава»**, **«Все детали по размерам»**. В первом варианте полный комплект пробуется как приоритет, но его непомещение не останавливает расчёт: отдельно собираются перед/спина, а если пара не помещается — отдельные корпуса. Рукава в первую очередь ищут место у собственного комплекта, затем у других комплектов того же размера; остаток собирается на дополнительных листах. Во втором варианте целый комплект заранее не закрепляется, чтобы рукава могли собираться общими листами. Третий вариант свободно компонует детали одного размера.
- На листах пресса **разные размеры не смешиваются**, в том числе при заполнении рукавами свободного места сбоку или снизу. Размер каждой детали передаётся в расчёт отдельно от текстовой подписи. Каландр и резка сохраняют свои прежние варианты группировки.
- Компоновка листов пресса учитывает мягкие правила: спинка слева, перед справа; левый рукав слева, правый справа, а при вертикальной паре рукавов правый выше левого. Для рукавов сначала учитывается собственный комплект, затем соседние детали того же размера. Поиск пробует оба порядка рукавов и сравнивает привычность компоновки при сопоставимом расходе бумаги. Дополнительный лист ради правила не создаётся; при нехватке места или существенной экономии допускаются исключения.
- Добавлены ориентация отрезного листа и его максимальная ширина. По умолчанию — вертикально, 750 мм; ширина включает четыре настраиваемых поля, 0 означает доступную ширину. Ограничения стола 120×80 / 120×100 см и рулона учитываются вместе. Прямоугольники уменьшаются до фактического заполнения и затем раскладываются на рулоне как отрезные листы. Настройки сохраняются в CDR проекта и в истории вариантов.

Сборка выполнена; новые листы пресса, интерфейс и захват миниатюры внутри CorelDRAW ещё не проверены. Размер PNG задан в пикселях через [StructExportOptions.SizeX](https://community.coreldraw.com/sdk/api/draw/26/p/structexportoptions.sizex).

## 1.1.63 · габариты печатных деталей в предпросмотре

- Печатные объекты детали сохраняются явным списком ссылок на контур, подпись и персональные надписи. Габариты объединяются из измерений каждого объекта после группировки, перемещения между слоями и поворота. Изменяемый состав Corel ShapeRange больше не используется для хранения печатного состава. Геометрия учитывает печатный припуск, обводки и надписи за пределами контура.
- Чтение `GetBoundingBox` использует изменяемые параметры, инициализированные NaN, и проверяет возвращённые координаты. Временный слой отключается для показа и печати после подготовки геометрии. Нулевые/неконечные габариты не заменяются вымышленными размерами и не исключают детали из заказа.
- Ошибки габаритов показывают размер формы, деталь, номер комплекта и фактические значения в мм. Подписи диагностики сохраняются при формировании пар/комплектов и листов пресса. При несовпадении габаритов после переноса/поворота показаны измеренный и рассчитанный размеры.

Справка API: [Shape.GetBoundingBox](https://community.coreldraw.com/sdk/api/draw/27/m/shape.getboundingbox?lang=cs), [ShapeRange](https://community.coreldraw.com/sdk/api/draw/26/c/shaperange). Сборка выполнена; повторный запуск печатной раскладки в реальном CorelDRAW ещё не проверен.

## 1.1.62 · данные формы внутри каждого CDR

Для записи на диск нужен **Ctrl+S**; внешние CDR/изображения сохраняются как ссылки, а не упаковываются в документ.
- Исправлена подтверждённая журналом ошибка `E_FAIL` при чтении `Document.CodeName`: идентичность документов определяется через COM IUnknown без CodeName, имени файла или индекса вкладки. Сохранение под другим именем не меняет привязку открытого проекта. Ошибки загрузки теперь видны в статусе и журнале, вместо молчаливой отмены редактирования.
- Таблицы игроков и шаблонов доступны для редактирования. Строки уведомляют об изменении всех полей; текст сохраняется при изменении значения, без ожидания завершения редактирования строки. Перед сменой проекта завершается редактирование обеих таблиц. Данные сохраняются в прежний документ по явной ссылке, даже если активной уже стала другая вкладка Corel. Открытые проекты имеют отдельные снимки в памяти; закрытые исключаются из этого кэша.
- Списки, сохранённые прежними версиями в CDR, подхватываются автоматически. Общий черновик прежней версии может быть принят только первым открытым документом без полного состояния; список этого CDR имеет приоритет над общим списком. Перед заменой общего черновика настройками по умолчанию сохраняется `sport-layout-draft.legacy.json`. Новые проекты не наследуют игроков, модель, шаблоны, рисунки и папки другого заказа. Галочки выполненных действий остаются в собственных свойствах CDR.

Сборка выполнена. Переключение двух CDR, редактирование и сохранение/повторное открытие в реальном CorelDRAW ещё не проверены.

## 1.1.61 · подбор раскладки и листовые прессы

- Кнопки подбора печати и резки открывают отдельное окно с контурным предпросмотром. Детали подготавливаются в Corel один раз на запуск, на временном слое; эта подготовка по-прежнему может занимать время. Дальнейшие варианты считаются в памяти в фоновом потоке, без повторного копирования рисунков и создания страниц. В окне можно менять ширину, длину, зазор, геометрию (прямоугольники / упрощённая / полный контур), группировку и разрешённые повороты. Для резки доступны только 0°/180°.
- Предусмотрены быстрый поиск и дополнительное уплотнение, остановка расчёта, масштаб предпросмотра, подписи комплектов и сохранение до десяти вариантов в текущем окне. Видны количество страниц, общая длина и время расчёта. Возврат к готовому варианту восстанавливает его настройки. Страницы создаются только кнопкой «Создать выбранный вариант в Corel», с координатами выбранного расчёта; закрытие окна удаляет временный слой и сохраняет прежние галочки этапов.
- Для печати добавлены «Каландр», «Пресс 120×80 см» и «Пресс 120×100 см». У пресса **четыре независимых поля**, по умолчанию 20 мм, с сохранением настроек. Сначала детали собираются в листы в пределах полезной зоны, затем целые прямоугольные листы размещаются на рулоне. Листы уменьшаются по заполнению; перебираются обе ориентации листа без поворота целых деталей. Предпочтение отдаётся меньшему числу прижимов, затем расходу бумаги. Подписи, припуски и язычки входят в геометрию соответствующей раскладки.
- В предпросмотре показаны границы отрезных листов и их число. Печать тонких светло-серых границ включается отдельной галочкой. Печать и резка сохраняют независимые параметры; режим пресса применяется только к печати. Подробная справка находится под «?».

Сборка выполнена. Новый сценарий подготовки, окно и перенос выбранных координат в реальном CorelDRAW, а также печать и работа на прессах ещё не проверены. Ручная расстановка не входит в эту версию.

## 1.1.60 · экспериментальная рулетка по кривой

- В **«Экспериментальное → Рулетка»** добавлен курвиметр. Инструментом **«Форма» (F10)** выберите ровно два узла одной кривой, затем нажмите **«Измерить между двумя узлами»**. Для замкнутого подконтура показаны меньший и больший участки между узлами; для открытого — один участок вдоль кривой.
- Длина складывается из штатных значений `Segment.Length`, включая сегменты Безье. Второй путь замкнутого контура вычисляется через `SubPath.Length`. Единицы исходного документа переводятся в миллиметры методом Corel `ConvertUnits`; отображение округлено до двух знаков. Прямая между точками при расчёте не используется.
- Измеряются два разных узла одного непрерывного подконтура. Несколько объектов, неподходящий тип, другое число узлов и разные подконтуры вызывают пояснение; старый результат сбрасывается. Форма кривой, узлы, единицы документа, выделение и файл не изменяются. Автоматического опроса нет; кнопка измерения не получает клавиатурный фокус, чтобы сохранить режим редактирования узлов.
- В панели видны документ, имя кривой, номер подконтура и индексы измеренных узлов. Отдельные числа и всё измерение можно скопировать. Подробная инструкция находится под мини-кнопкой «?».

Использованы документированные API Corel: [Curve.Selection](https://community.coreldraw.com/sdk/api/draw/27/m/curve.selection?lang=vb), [Segment.Length](https://community.coreldraw.com/sdk/api/draw/27/p/segment.length?lang=vb), [Node.AbsoluteIndex/Index](https://community.coreldraw.com/sdk/api/draw/26/p/node.absoluteindex) и [ConvertUnits](https://community.coreldraw.com/sdk/api/draw/26/m/ivgapplication.convertunits). Сигнатуры также прочитаны из установленной библиотеки типов Corel 27. Сборка выполнена; выбор узлов и измерения в реальном CorelDRAW ещё не проверены.

## 1.1.59 · папка заказчика при выборе CDR и фото только в кадрах

- Фотографии заказа загружаются только в блок «Кадры» карточки. Серверные кадры содержат растровый снимок и миниатюру, без ссылок на объекты холста. У такого кадра отключена кнопка выделения объектов; просмотр открывается по миниатюре. Подписи загрузки и привязки уточняют место загрузки фотографий.
- При выборе CDR для заказа без назначенного файла используется актуальная сохранённая папка года, в том числе в отдельном окне «Заказы». Неприменённый ввод папки в текущей панели учитывается отдельно. Настройка может указывать сам год или родительскую папку с каталогами годов.
- Сначала ищется папка заказчика в месяце заказа, включая варианты имени месяца, регистра, пробелов и нормализации Unicode. Если её нет, используется единственное совпадение в других месяцах этого года. При нескольких совпадениях открывается папка месяца, затем года. Чтение каталогов выполняется вне потока интерфейса; папки не создаются.
- Окно выбора CDR использует системный `IFileOpenDialog.SetFolder`, чтобы стартовать в рассчитанной папке, независимо от ранее посещённого каталога. Выбирается один существующий `.cdr`; рассчитанная папка и ID заказа записываются в журнал. См. [описание SetFolder в Microsoft Learn](https://learn.microsoft.com/en-us/windows/win32/api/shobjidl_core/nf-shobjidl_core-ifiledialog-setfolder).

Сборка выполнена. Выбор сетевого CDR и поведение диалога внутри CorelDRAW ещё не проверены.

## 1.1.58 · фотографии карточки и две этикетки из Corel

- При открытии заказа из списка, загрузке по номеру, привязке и команде «Загрузить карточку с сервера» фотографии заказа загружаются в список «Кадры». Левая использует выбранный формат, правая — клиентский шаблон полной этикетки и настроенный принтер полного формата. В очередь передаётся `labelVariant=detailed/customer`; незавершённые задания различаются по варианту, чтобы повторная кнопка проверяла прежнее задание без дублирования.

## 1.1.57 · поля карточки заказа при открытии и привязке CDR

- При привязке CDR к существующему заказу из списка загружается полная карточка сервера: заказчик, источник, технологии, описание, изделия, срок, срочность, доставка и текстиль клиента. Заполненные поля старой карточки CDR больше не имеют приоритета. После привязки CDR сохраняется.
- При повторном открытии уже связанного файла из списка заказов карточка также перечитывается с сервера. Обновлённые поля записываются в открытый документ; для сохранения в файл используется Ctrl+S или «Сохранить CDR». При связывании заказа «без макета» применяются поля его серверной карточки. Имя макета, объекты и кадры остаются в CDR.

## 1.1.48 · цветной ряд кнопок печати и ICC

- Пять кнопок на главной вкладке всегда идут в один ряд: **красная DTF → синяя DTF → зелёная UV → жёлтая UV → SUB**. Перенос по ширине отключён; короткие подписи помещаются в узком докере.
- Сами кнопки имеют цветную заливку. Без выделения DTF/UV сохраняют приглушённый цвет, оставаясь неактивными. SUB имеет нейтральную серо-синюю заливку. Пунктирная мини-рамка есть только у жёлтой UV; её цвет меняется вместе с состоянием кнопки.
- Папки, требования к выделению и подтверждение печати активного листа для SUB сохранены.
- Параметры пяти кнопок: PDF 1.7, масштаб 1:1, текст кривыми, исходные RGB/CMYK. DTF/UV — ZIP без потерь и без понижения разрешения. SUB — JPEG 95%, цветные/серые растры до выбранных 150/300 DPI (по умолчанию 300), монохромные до 1200 DPI. Вектор сохраняется, сжатие текстовых и векторных потоков включено.
- В **«Настройки → Печать PDF, DTF и UV · папки и ICC»** у каждой из пяти кнопок собственный режим: **«Как в Corel»**, **«Удалить ICC»** или **«Выбранный входной ICC»**. По умолчанию выбран первый режим, прежние папки сохраняются. Файл ICC/ICM выбирается отдельно для каждой кнопки и проверяется при сохранении и экспорте. Для назначения поддерживаются обычные ICC версии 2/4 для RGB и CMYK; DeviceLink и специальные классы выбираются в RIP.
- Назначение выбранного ICC меняет описание цвета, сохраняя значения каналов: RGB-профиль применяется к RGB-объектам, CMYK — к CMYK. Другие модели сохраняют исходные профили. Цветовые модели групп прозрачности и серые маски непрозрачности не переназначаются. При удалении ICC пространства заменяются на соответствующие DeviceRGB/CMYK/Gray и убираются выходные ICC. Страница, векторные операторы и образцы растров не пересчитываются. Профиль принтера/материала и преобразование настраиваются в RIP, где нужно разрешить входные профили; назначение другого входного профиля может изменить интерпретацию цветов.
- Обработка ICC выполняется отдельным PDF-модулем после восстановления исходного CDR и до передачи задания. Проверяются профиль, размер PDF 1:1 и наличие выбранного профиля либо отсутствие ICC в сохранённом PDF. При ошибке готовый PDF в папке RIP не появляется. Фотовывод продолжает использовать своё прежнее удаление ICC.
- Для отправки выделения, в том числе из режима фокус-группы, реальные объекты переносятся в отдельный временный CDR с цветовым контекстом исходника. Проверяются габариты после вставки и перемещения, явно задаётся размер страницы; затем экспортируется эта страница целиком. Исходный CDR и выделение восстанавливаются. PDF проверяется перед отправкой при любом режиме ICC; режим сохранения ICC оставляет байты PDF без изменений. Проверка пустоты структурная: учитываются рисующие контуры, текст, растры, вложенные Form и заливки; белые и плашечные объекты допустимы. Проверка не заменяет визуальный просмотр эффектов прозрачности и отсечения. При ошибке размера сообщение показывает ожидаемые и полученные габариты. Сохраняется ограничение печатного экспортера: сторона до 5080 мм, без уменьшения масштаба.

Сборка выполнена; вид кнопок и новые режимы ICC в CorelDRAW/RIP пока не проверены.

## Новый основной путь: native addon без `.gms`

Чтобы установка была солидной и переносимой на другие ПК, проект переводится на C#/.NET addon:

- `native/VanyaTools.Native` - WPF docker control и логика команд.
- `addon/VanyaToolsNative` - CorelDRAW addon, который загружает `VanyaTools.Native.dll`.
- `build-native.ps1` - сборка DLL.
- `install-native.ps1` - установка в CorelDRAW `Programs64\Addons`.
- Статическая справка во всех вкладках открывается маленькими кнопками **«?»** рядом с действиями и настройками. Наведите курсор для подсказки или нажмите для чтения и копирования текста; щелчок снаружи или Esc закрывает справку. Ошибки, результаты операций и подписи полей остаются видимыми.
- Вкладки открываются миниатюрами; названия видны при наведении. «Основная» содержит обрезку растра, удаление фона, апскейл и подготовку ДТФ; фотоинструменты собраны в «Фото и ИИ». В «Настройках» находятся обновление и ключ Replicate.
- Интерфейс рассчитан на узкий докер: подписи остаются рядом со своими полями, длинные названия кнопок и галочек переносятся внутри элемента, миниатюры стилей меняют число столбцов по доступной ширине. «Основная» прокручивается, а поля заказчика и имени макета остаются снизу.
- Выделите объект или группу; для AI-запросов векторы преобразуются во временный PNG, исходники сохраняются. Результат вставляется на холст автоматически. При сбое вставки нажмите «Повторить вставку» без повторной генерации.
- Апскейл ×2 использует Real-ESRGAN с внутренней обработкой изображения по фрагментам, чтобы избежать переполнения памяти GPU. Локальные инструменты кромки удаляют полупрозрачные пиксели по порогу альфа-канала (по умолчанию 130), отдельно сглаживают ступеньки на более плотной сетке пикселей или создают обводку с заданными радиусом и расширением. Во всех случаях альфа-канал результата содержит только 0 и 255. DPI увеличивается вместе с числом пикселей, поэтому физический размер сглаженного изображения сохраняется. Новые пиксели обводки получают плотный цвет подложки. Нажатие на цветной квадратик рядом с HEX открывает окно выбора цвета с палитрой, оттенками и вводом RGB; окно открывается на текущем цвете, а «Отмена» сохраняет прежнее значение. Также доступны ручной ввод HEX и экранная пипетка. Исходные объекты сохраняются.
- В «Фото и ИИ» четыре отдельные вкладки: «Заливка», «ИИ промпт», «ИИ стили» и «Стили». Готовые ИИ-стили включают шесть пресетов, включая «Городскую иллюстрацию». Обычные стили выбираются по миниатюрам, которые после загрузки выделения показывают эффекты на вашем фото.
- Во вкладке «Экспериментальное → Шрифт» можно подготовить PNG выделенных букв и открыть WhatTheFont для поиска по базе шрифтов. PNG загружается пользователем на сайте. Прежний анализ через Claude/DeepSeek перенесён туда же и свёрнут; он даёт предположения, а не точное распознавание. Восстановление принта находится в соседней вкладке внутри «Экспериментального».
- В восстановлении принта анализатор подробнее описывает мелкие мазки, края, вырезы и перекрытия; промпт просит сохранить эти элементы и исходную толщину букв.
- В полном режиме восстановления выделение захватывается в 400 DPI, крупные PNG загружаются в Replicate файлом, FLUX.2 Pro получает настройку до 4 MP, апскейл выполняется до и после генерации, а полупрозрачные края проходят локальную коррекцию матового цвета.
- В «Основной» белый фон можно удалить локально без снижения разрешения для модели: удаляются только светлые области, связанные с краем изображения. Параметр «Подрезать, px» сдвигает край внутрь на 0–8 пикселей, если остался белый ореол. Для сложного фона Bria создаёт маску, которая накладывается на исходный растр с его размером и цветами.
- Финальный A3-вывод масштабируется высококачественным фильтром; авто-палитра сохраняет до восьми оттенков и больше не схлопывает тона одного цвета. Полноцветный вывод доступен отдельно.
- Во вкладке «Развёртка формы» выделите весь мокап, затем выберите перед, спинку или рукав. На виде спереди правый рукав находится слева на изображении, левый — справа. Размер по умолчанию: 550 × 750 мм для переда и спинки, 450 × 300 мм для рукава. Нажмите «Создать развёртку из выделения». Крупное выделение автоматически уменьшается перед запросом. Claude находит нужную деталь; для рукава FLUX.2 Pro получает только его фрагмент. Если рукав не найден, генерация не запускается. Real-ESRGAN увеличивает четыре фрагмента по выбору. Плагин собирает непрозрачный PNG 300 dpi и вставляет его на холст; лекало добавляется в CorelDRAW. Для нового размера создайте новую развёртку из мокапа. После отмены или сбоя нажмите «Продолжить / повторить вставку» — готовые этапы повторно не оплачиваются.
- Незавершённая развёртка сохраняется между перезапусками CorelDRAW. Для заданий, начатых в 1.0.72, плагин находит последний сохранённый мокап и готовые этапы; перед продолжением проверьте выбранную деталь и размеры.
- Во вкладке «Публикация» кнопка «Добавить выделение» сразу сохраняет кадр как растровое фото высокого разрешения. При отправке используются готовые снимки, поэтому последующее разгруппирование или изменение объектов не ломает кадры. Кнопка ↻ рядом с кадром переснимает текущее выделение. Для сохранённых CDR снимки хранятся в соседней папке `.vanya-frames`; при переносе CDR на другой компьютер переносите и эту папку.
- При обновлении заказа с одним кадром докер спрашивает, переснять ли текущее выделение перед отправкой. Это позволяет заменить фотографию прямо кнопкой «Заменить фото и обновить текст»; после отправки список заказов обновляется автоматически.

Сборка и установка:

```powershell
.\install-native.ps1 -Build
```

Если установка в `Program Files` ругается на права, запустить PowerShell от имени администратора и повторить команду.


Установщик найдёт папку CorelDRAW, предложит выбрать версию, если их несколько, и запросит права Windows только при необходимости. Если программа установлена в нестандартное место, установщик попросит путь к `Programs64` или `Programs64\Addons`.

После установки перезапустите CorelDRAW и откройте `Окно > Окна настройки (Dockers) > Vanya Tools Native`. Список заказов можно открыть отдельным докером `Vanya Tools — Заказы` через вкладку «Заказы» или то же меню CorelDRAW.

Если на одном ПК кнопки присутствуют, а на другом отсутствуют при одинаковой версии плагина, проверьте рабочую среду Corel. Автоматическая вставка кнопок через `UserUI.xslt` относится к конкретной стандартной панели и сохранённой рабочей среде. Откройте докер через меню «Окно», перейдите в «Настройки» и нажмите **«Восстановить кнопки на панели Corel»**. Будет показана отдельная перемещаемая панель **Vanya Tools** с открытием докера, обрезкой и рамкой. Повторная команда добавляет только недостающие кнопки на этой панели. Стандартные панели и пользовательская рабочая среда не сбрасываются. Если команды не зарегистрированы в Corel, установите полный ZIP через `INSTALL.bat` и перезапустите Corel. Одинаковый номер DLL не подтверждает наличие всех файлов интерфейса.

### Фотовывод: позитив на плёнке

Новая вкладка **«Фотовывод»** открывается чёрно-белой иконкой метки совмещения. Интерфейс рассчитан на узкий докер. Основные действия:

- **«Всё выделение»**: выделите цветной эталон и поставьте метки перед разделением по цветам. **«Каждый выбранный растр отдельно»**: выделите готовые полутоновые растры; каждый получает собственный комплект меток и свой PDF. Порядок — сверху вниз, внутри ряда слева направо.
- **«Поставить / обновить метки и подпись…»** открывает таблицу цветов и номеров слоёв. Два концентрических круга Ø8/Ø5 мм и три отрезка по 10 мм (горизонталь, вертикаль и диагональ 45° вправо) имеют общий центр. Пара меток лежит на вертикальной оси середины ширины рисунка, на 25 мм выше и ниже его краёв. Контур по умолчанию 0,15 мм, C0 M0 Y0 K100. Справа снизу от нижней метки — цвет и номер слоя, Arial 6 пт.
- Рисунок и разметка объединяются в комплект. При повторном применении к комплекту подпись обновляется **без перемещения существующих меток**, в том числе после разделения эталона. Для новой геометрии меток разгруппируйте комплект и выделите только исходный рисунок. Дополнительные объекты внутри комплекта сохраняются. Изменение разметки и полос имеет одну команду отмены.
- **Таблица пар меток** показывает все пары Vanya Tools в открытом CDR, включая другие страницы. При копировании или удалении пары список обновляется автоматически, пока вкладка видна. Каждая копия имеет отдельную строку, независимо от совпадения цвета и номера. В таблице редактируются название цвета и номер слоя; Enter или выход из ячейки применяет подпись к соответствующей паре. Есть кнопки применения правок, обновления списка, выбора пары на холсте и сброса незаписанных правок. Новая пара объединяет обе метки и подпись в собственную группу внутри комплекта: обычное копирование переносит их вместе. Старые комплекты также отображаются; для отдельно скопированных старых меток без подписи она создаётся при редактировании строки. Цвет и номер хранятся в CDR, изменения поддерживают Undo. Переключение документа не переносит подписи в другой файл.
- **Боковые полосы** можно добавить отдельной кнопкой либо только при экспорте. По умолчанию они идут на всю высоту вывода на расстоянии 20 мм от содержимого, ширина 0,3 мм. На верхних и нижних концах — поперечные риски длиной 2 мм внутрь. Размеры и отступы настраиваются. Габариты всегда измеряются в миллиметрах независимо от единиц документа; исходные единицы восстанавливаются. Повторная кнопка заменяет прежние полосы, в том числе ошибочно уменьшенные в 1.1.37. Постоянный резерв под подпись сохраняет одинаковую длину при одинаковых габаритах и метках; разная длина названий цветов не меняет высоту.
- Доступная ширина плёнки по умолчанию **605 мм**. Если включено сближение полос, уменьшается только зазор, не меньше 2 мм. Сам рисунок не масштабируется. Если места недостаточно, разметка полос или экспорт останавливаются с сообщением. При необходимости уменьшите доступную ширину на непечатаемые поля своего принтера. Непрерывные полосы создают печатную область по высоте; фактический режим проходов определяется RIP и принтером.
- **«Проверить цвета выделения»** проверяет группы, вложенные PowerClip, текстовые заливки, обводки и исходные пиксели растров. Для вектора допустимы только K100 без CMY и белый RGB 255/255/255 или CMYK 0/0/0/0. RGB-чёрный, составной чёрный, цветные и spot-цвета — ошибки. Оттенки серого, нейтральные RGB-растры, прозрачность и монохромные растры — предупреждения. Полностью прозрачные пиксели пропускаются. Цветовой порядок байтов не угадывается: Corel читает цвет каждого нового значения исходного пикселя. Неподдерживаемые заливки и ошибки чтения блокируют экспорт; исходные цвета не исправляются автоматически.
- При ошибках автоматически раскрывается **список ошибок и предупреждений** с объектом, причиной и доступной правкой. В таблице хранится весь список, даже если текстовый отчёт ограничен первыми 80 замечаниями. **«Выделить все ошибки»** выбирает ошибочные объекты в Corel без объектов с одними предупреждениями; **«Выделить строки»** выбирает объекты отмеченных через Ctrl/Shift строк. Можно перекрасить их вручную и нажать **«Проверить снова»**: проверяется весь исходный фотовывод, его выделение восстанавливается.
- **«Ошибочные цвета → K100»** по явному нажатию заменяет только недопустимые цвета векторных заливок, обводок, отдельных букв и точек градиента на C0 M0 Y0 K100. Белый, разрешённые полутона, форма объектов и отсутствие заливки/обводки сохраняются; вся правка отменяется одним Ctrl+Z. Перед изменением читаются текущие цвета, после него выполняется повторная проверка. Растры, сложные заливки, эффекты и недоступные данные отмечаются **«Вручную»** и остаются доступными для выделения. Экспорт и передача в RIP требуют устранить оставшиеся ошибки. Кнопка **«Вернуть исходное выделение»** выбирает весь проверенный вывод. Временное выделение ошибок также восстанавливается перед разметкой или экспортом, если пользователь не выбрал другие объекты самостоятельно; после смены документа нужна новая проверка.
- Объекты проверки находятся по фактическому составу выделения, групп, PowerClip и слоёв CDR, включая рабочий стол и мастер-слои; поиск не ограничивается `Page.FindShape` по активной странице. **«Проверить снова»** сохраняет область исходного вывода. **«Проверить новое выделение»** в списке и основная кнопка **«Проверить цвета выделения»** начинают новую проверку текущего выделения, сбрасывая старый список без попытки найти объекты прежней проверки. После изменения состава сначала выделите весь нужный фотовывод. Если объект действительно недоступен, сообщение содержит его ID и указывает эту кнопку; детали записываются в журнал.
- **PDF 1:1** создаётся в отдельном временном документе с цветовым контекстом исходного CDR. Используется буфер обмена для переноса копии. Исходный рисунок и настройки PDF исходного документа сохраняются. Временная страница содержит только выбранный фотовывод; её размер явно рассчитывается по содержимому, меткам и полосам, затем экспортируется вся эта страница. Corel не пересчитывает габариты выделения при публикации. При включённых полосах они заново строятся в PDF по текущим размерам. Принудительно задаются: исходные цвета, отсутствие сжатия и субдискретизации, текст кривыми, отсутствие типографских меток, полутоновых настроек и шифрования. Ошибки цветов блокируют экспорт, предупреждения о полутонах остаются в отчёте.
- **Заготовка `filmgate` не требуется.** На каждом ПК параметры задаются плагином: PDF 1.7 (совместим с Acrobat DC), исходные цвета и прочие перечисленные выше настройки. Из-за `E_NOTIMPL` в API Corel для ICC-профилей готовый временный PDF обрабатывается входящим в пакет модулем на основе [PDFsharp](https://docs.pdfsharp.net/): ICCBased заменяются на DeviceGray/RGB/CMYK с тем же числом каналов, удаляются выходные ICC-профили и переопределения Device-цветов. Числа цветовых каналов, пиксели и контуры не пересчитываются; макет не растрируется. Перед выдачей файла модуль проверяет размер страницы 1:1 и отсутствие ICC-ссылок. Отдельно устанавливать библиотеки или менять пользовательские заготовки Corel не нужно.
- Уже созданный комплект можно экспортировать и после удаления/разворачивания служебной группы рисунка: для поиска содержимого исключаются только собственные метки, подпись и полосы. Именованная группа исходного рисунка не обязательна; растровому фотовыводу отдельный контур не нужен.
- Папка экспорта: **папка года → папка месяца → `фотовывод`**. Папка года берётся из пути сохранённого заказа либо общей настройки CDR; для сохранённого заказа используется его месяц, для остальных — текущий месяц. Пример: `2026/10октябрь2026/фотовывод`. Имя PDF содержит имя CDR, цвет и номер слоя; существующие файлы не перезаписываются. Готовые PDF появляются в папке только после подготовки всей выбранной серии. При печати выбирайте **1:1**, без вписывания в лист.
- **«Отправить на печать в RIP»** использует тот же PDF, выделение, режим отдельных растров, полосы и проверку цветов, но сохраняет файлы непосредственно в hot folder. Путь задаётся отдельно в **«Настройки → Фотовывод · печать в RIP → Hot folder»**, сохраняется на этом ПК и не зависит от папки года. Поддерживается сетевой UNC-путь. Папка должна существовать; при её недоступности задание не отправляется. PDF получает уникальное имя с временем и кодом задания; расширение `.pdf` появляется после полной записи. В серии сначала готовятся все файлы. Статус означает передачу файлов в папку, а дальнейшую обработку и запуск принтера выполняет RIP. При частичном сбое выводится список уже переданных заданий для проверки очереди перед повторной отправкой.
- Проверка размеров PDF учитывает поворот страницы и `/UserUnit`; допускается округление границ страницы до 0,2 мм. Содержимое не масштабируется. При реальном расхождении показываются ожидаемые и полученные размеры, поворот и масштаб; исходный проблемный PDF сохраняется локально в `VanyaTools/Diagnostics/FilmPdfSizeError.pdf` для диагностики. Ошибка размеров больше не обозначается как ошибка удаления ICC.

### Обводка ДТФ: миллиметры и пиксели

В «Основной» обводка задаётся в **мм** по умолчанию. Список **мм/px** переключает единицы для наружного расширения и радиуса сглаживания с пересчётом туда и обратно. Под полями показаны целые пиксели обработки и получившиеся миллиметры. Пересчёт до запуска использует оценку DPI захвата текущего выделения; после захвата — действительные DPI X/Y PNG. Без выделения расчёт предварительный. Физическая толщина в миллиметрах сохраняет смысл при изменении размера захвата.

Две мини-кнопки с **тонким и толстым контуром** заполняют наружную обводку с каждой стороны; сглаживание и цвет задаются отдельно. Подсказки при наведении показывают текущие значения: по умолчанию +0,175 и +0,3 мм. Значения обоих пресетов можно поменять в **«Настройки → ДТФ · пресеты обводки»** и сохранить. Допустимы точка и запятая. Пресеты хранятся на этом ПК, диапазон 0,001–5 мм.

Растр требует округления: например, 0,175 мм при 400 DPI — 2,756 px, при обработке **3 px ≈ 0,1905 мм**. Положительное значение занимает хотя бы один пиксель. Предел сглаживания — 12 px, наружного расширения — 100 px; при превышении выводится соответствующий предел в миллиметрах для текущего DPI. Размер PNG после обводки увеличивается за счёт добавленных полей; положение корректируется относительно исходной графики.

### Экспериментальное: шум ДТФ и шрифты

**«Шум ДТФ»** работает локально без Replicate. Загрузите выделение и сравните центральный фрагмент до/после. Сила 0–5% задаёт максимальное случайное отклонение от исходного значения RGB-каналов: во все три канала добавляется одинаковая величина, затем результат ограничивается диапазоном 0–255. При 1% отклонение до ±2,55 уровня. По умолчанию сила 0,5%; чистый белый и чистый чёрный защищены отдельной галочкой. Альфа-канал не меняется, новые точки за прозрачной областью не появляются. Цвет при ограничении каналов может измениться. Размеры в пикселях, DPI и физический размер полной копии сохраняются.

Предпросмотр берёт центральные пиксели исходника; координаты и выбранный рисунок шума совпадают с полной обработкой. Кнопка **«Другой рисунок шума»** меняет зерно. **«Тестовый лист шума · 0–5%»** создаёт восемь подписанных квадратов: **0 / 0,5 / 1 / 1,5 / 2 / 3 / 4 / 5%**, четыре столбца и два ряда. Размер квадрата выбирается: **5×5 или 10×10 см** (с точностью до пикселя исходного DPI). Берётся центральный фрагмент 1:1; маленький исходник увеличивается с сохранением пропорций до заполнения квадрата, шум добавляется после увеличения. Лист вставляется в исходном DPI; печатайте 1:1 с одинаковыми параметрами CADlink/PrintExp. Исходник сохраняется. Готовый результат при сбое вставки можно вставить повторно, в том числе после перезапуска Corel.

Шум — эксперимент по изменению визуальной заметности полос, а не гарантированное устранение banding. Для проходных полос DTF [Inèdit рекомендует сравнить feathering и направление печати](https://inedit.freshdesk.com/en/support/solutions/articles/14000166486-resolving-horizontal-banding-on-dtf-prints). [Руководство Epson по DTF](https://files.support.epson.com/docid/other/cmp0437-00_en.pdf) отдельно описывает проверку дюз и подачи. Результат именно на вашем принтере должен оцениваться по пробному отпечатку; работа нового инструмента внутри Corel и на печати ещё не проверена.

**«Шрифт»** находится в этом же экспериментальном разделе. Подготовка PNG сохраняет контуры букв, добавляя контрастный фон для прозрачных участков. Кнопка открывает [WhatTheFont от MyFonts](https://www.myfonts.com/pages/whatthefont); загрузите подготовленный файл на сайте, вставив скопированный путь в окно выбора файла. Это переход к специализированному сервису с ручной загрузкой изображения, а не встроенный API: плагин сам не отправляет образец в WhatTheFont. Прежний платный ИИ-анализ расположен ниже в закрытом блоке и по-прежнему является визуальной оценкой. **«Восстановление принта»** открывается отдельной вкладкой рядом с шумом и шрифтом внутри «Экспериментального».

### Фото и ИИ

| Вкладка | Работа |
| --- | --- |
| Заливка | Правка области прямоугольника или расширение краёв фото с сохранением исходника вне маски. |
| ИИ промпт | Обработка выделенного фото целиком по своей команде: сменить фон, свет, одежду или убрать предмет. |
| ИИ стили | Готовые стили: аниме, наивная иллюстрация, 3D-персонаж, акварель, комикс и городская иллюстрация. Промпт выбранного стиля можно уточнить. |
| Стили | Локальные эффекты без интернета: чёрно-белый, сепия, благородное золото, тёплый матовый, серо-коричневый винтаж и свой тон. |

Во вкладках «ИИ промпт» и «ИИ стили» доступны **Nano Banana 2**, **Nano Banana Pro**, **Seedream 4.5**, FLUX.2 Pro, FLUX.1 Kontext Max и Qwen Image Edit. Новые модели получают исходное фото в поле `image_input`, согласуют пропорции с исходником и работают в 2K. Проверены публичные схемы [Nano Banana 2](https://replicate.com/google/nano-banana-2/api/schema), [Nano Banana Pro](https://replicate.com/google/nano-banana-pro/api/schema) и [Seedream 4.5](https://replicate.com/bytedance/seedream-4.5/api/schema). Ориентировочная цена одного результата на 18 октября 2026: $0.101, $0.15 и $0.04 соответственно; цена выбранной модели показывается в интерфейсе и перед отправкой. Для Seedream задан один результат, автоматическая подмена Nano Banana Pro другой моделью отключена. Платные запросы и качество новых моделей внутри Corel ещё не проверены.

Промпты, выбор модели, предпросмотры и готовые результаты каждой вкладки независимы во время работы докера. Готовый, но ещё не вставленный результат сохраняется отдельно для каждого режима и доступен после перезапуска без повторной генерации. Обычные стили сохраняют загруженное выделение при переключении вкладок; кнопка обновления выделения загружает другое фото.

Карточки обычных стилей используют **тот же алгоритм**, что и обработка полного изображения. До загрузки фото они показывают общий рисованный образец. Нажмите «Загрузить выделение для предпросмотра», чтобы все миниатюры и большой предпросмотр строились по вашему фото. Сила эффекта и тонкая настройка обновляют карточки; нажатие «Применить локальный стиль» обрабатывает полное выделение. ИИ-миниатюры показывают ориентир стиля, а итог зависит от модели.

### Генеративная заливка фотографии

Во вкладке «Фото и ИИ → Заливка» выделите **один растровый объект и один прямоугольник**. Если прямоугольник выходит за края фотографии, он задаёт расширение кадра: можно обвести весь исходник рамкой желаемых пропорций. Исходная фотография сохраняется, дорисовывается только новая площадь с узкой полосой совмещения у расширяемых краёв. Прямоугольник целиком внутри фотографии задаёт локальную область замены. Напишите свой промпт в единственном поле и нажмите «Дорисовать выделенную область». Последний промпт сохраняется на этом ПК. Исходные объекты остаются на холсте, а результат вставляется рядом. Пиксели вне фактической маски берутся из исходного изображения. Нужен ключ Replicate в настройках; каждый запуск модели оплачивается по тарифу Replicate.

Для заливки доступны **Nano Banana 2** (по умолчанию) и **Nano Banana Pro**, обе в 2K. Достаточно короткой команды на русском: «дорисуй сверху», «убери бутылку», «восстанови руку». Инструмент передаёт одну фотографию с цветовой разметкой области правки, автоматически добавляет указания продолжать тот же кадр, сохранить масштаб людей, ракурс и освещение. Выбор модели сохраняется. По тарифам Replicate на 16 октября 2026 года результат 2K стоит ориентировочно $0.101 для [Nano Banana 2](https://replicate.com/google/nano-banana-2) и $0.15 для [Nano Banana Pro](https://replicate.com/google/nano-banana-pro); цена выбранной модели показывается перед отправкой. Выполняется один запрос изображения, без отдельного платного анализа и автоматической смены модели.

Перед отправкой холст дополняется до поддерживаемых моделью пропорций без обрезки фотографии; после получения результата техническое дополнение отрезается. В единственном RGB-изображении для модели новые области помечаются сплошным пурпурным цветом, а правка по существующим пикселям — полупрозрачным оттенком, сохраняющим видимый контекст. Nano Banana принимает изображения-референсы, а не отдельный параметр маски ([схема API](https://replicate.com/google/nano-banana-2/api/schema)); чёрно-белая маска остаётся локально для точного совмещения. Исходный файл хранится отдельно. Пиксели чёрной области маски восстанавливаются из него, граница правки мягко совмещается. Ответ с неверными пропорциями отклоняется вместо растягивания. Повтор после ошибки сети продолжает тот же запрос; готовый ответ модели используется повторно при ошибке совмещения или вставки. Качество продолжения зависит от модели; сохранение исходных пикселей не гарантирует правильную дорисовку новых областей.

### Вкладки раскладки спортформы

Раскладка открывается пятью вкладками сверху: **Лекала / Рисунки / Игроки / Печать / Резка**. PDF находится в «Печати», DXF и сохранение CDR резки — в «Резке». Выполненные шаги отмечаются зелёной галочкой; отметки записываются в рабочий CDR при его сохранении, не сбрасываются из-за смены COM-обёртки и восстанавливаются при возврате к документу. Изменение исходных данных снимает зависимые отметки. Плотность выбирается из прямоугольников, упрощённых фигур и полного контура; детали можно укладывать свободно, парами перед/спина с последующими рукавами или целыми комплектами. Плотность и группировка задаются независимо для печати и резки: изменение режима одной раскладки не снимает галочку другой. Подробности — в [описании инструмента](SPORT_TEMPLATE.md#вкладки-раскладки-и-отметки-шагов).

### Выбор деталей печати спортформы

В таблице игроков у деталей **«Перед»**, **«Спина»**, **«Лев. рук.»**, **«Прав. рук.»**, **«Горловина»** появились отдельные галочки печати. Галочка в заголовке меняет деталь сразу у всех строк. Для формы с непечатными левым рукавом и горловиной снимите эти два столбца: в печать они не попадут, в резку войдёт полный комплект. Общая галочка «Печатать» выбирает строку заказа для печати и резки; при снятых всех галочках деталей строка остаётся только для резки. Выбор сохраняется в черновике и при вставке поверх строк. Изменение галочек деталей не сбрасывает отметку готовой резки. Кнопка ↗ создаёт отдельную деталь для допечатки по явному запросу.

### Подготовка выбранных размеров спортформы

Сначала заполните таблицу игроков и отметьте строки галочкой **«Печатать»**. Этап 1 готовит только уникальные размеры этих строк. Готовые макеты остаются на своих слоях; повторный запуск добавляет только новые размеры на ту же обзорную страницу и сохраняет ручные правки. Например: S и M → подготовка двух размеров; затем добавленный L → подготовка только L. Если новых размеров нет, исходные модели и рисунки не открываются. Для пересоздания одного макета удалите его слой размера и повторите этап 1. Подробности — в [SPORT_TEMPLATE.md](SPORT_TEMPLATE.md).

### Захват рисунков для спортформы

По умолчанию **«Взять выделение из Corel»** сохраняет выбранные объекты отдельным **CDR**. Кривые, текст, заливки и группы сохраняют свою структуру; встроенные растры остаются растрами. Исходный документ не переименовывается, его рисунок не меняется. Этап 1 создаёт независимую группу рисунка для каждого размера. Поправьте элементы внутри группы на слое нужного размера через Ctrl+щелчок; этап 2 использует этот вариант и помещает его в PowerClip контура. Сохраняйте внешнюю группу рисунка детали. Поддерживаются CDR и прежние файлы PNG/JPG/TIFF/BMP.

У каждой детали есть **«Обновить в макетах»**: замена только её рисунка в уже подготовленных размерах отмеченных игроков. Лекала, текстовые образцы и подписи сохраняются; ручные изменения заменяемого рисунка сбрасываются. Операция отменяется одним Ctrl+Z. Для старых захватов PNG возьмите рисунок заново из исходных векторных объектов и нажмите обновление: готовый растр автоматически не векторизуется. Обычный повтор этапа 1 по-прежнему добавляет только недостающие размеры.

Отдельный режим **«PNG · снимок 300 DPI»** сохраняет прежний растровый захват. Только для него выбирается предел **100, 150, 200 или 250 Мп**, по умолчанию **150 Мп**. Выбор режима и лимита запоминается на этом ПК. Перед созданием временной копии и перед растрированием плагин проверяет доступную ОЗУ и запас выделяемой памяти Windows. При недостатке памяти операция останавливается с оценкой необходимого запаса; DPI автоматически не уменьшается. Дополнительный предел — 20 000 пикселей по каждой стороне. Это лимит отдельного PNG, а не всей печатной раскладки; для копии объектов CDR он не применяется.

Для 32-битного растра каждый пиксель занимает 4 байта: 150 Мп — около 600 МБ, 250 Мп — около 1 ГБ без сжатия ([Microsoft: PixelFormat](https://learn.microsoft.com/en-us/dotnet/api/system.drawing.imaging.pixelformat?view=netframework-4.8.1)). При захвате используются дополнительные копии и рабочие буферы. Проверка закладывает 24 байта на пиксель, 256 МиБ служебного запаса и резерв не меньше 1 ГиБ. Это консервативная оценка для отказа до захвата, а не измеренный пик памяти или гарантия отсутствия сбоев Corel. Общий расход зависит также от сложности исходного документа, открытых CDR и числа экземпляров рисунка. Подробности — в [SPORT_TEMPLATE.md](SPORT_TEMPLATE.md#память-при-захвате-рисунка).

### Экспорт раскладки спортформы для печати

После этапа 2 откройте лист печати, выберите **«Папка печати…»** и нажмите **«Экспортировать активный лист печати в PDF»**. Экспортируется только активная страница целиком, в масштабе 1:1. Папка запоминается; каждый экспорт создаёт новый файл с номером страницы и временем. Компактный режим ограничивает фотографии 150 DPI, детальный — 300 DPI; JPEG-качество 95%, надписи выводятся кривыми и остаются векторными. Это позволяет не создавать единый растр размером во весь рулон. Физические размеры, размер файла и путь показаны после сохранения. Подробности и ограничение размера PDF — в [SPORT_TEMPLATE.md](SPORT_TEMPLATE.md#экспорт-листов-печати). Corel поддерживает [сжатие изображений и векторных потоков в PDF](https://help.coreldraw.com/CorelDRAW/540111192/Documentation-Windows/CorelDRAW-en/CorelDRAW-Reduce-PDF-file-size.html).

Ширина бумаги для печати и ширина ткани для резки задаются отдельно. Для резки можно включить П-образные язычки: по умолчанию 24×12 мм, два непрорезанных мостика по 2 мм, однолинейные символы высотой 8 мм. Размеры настраиваются; положение от начала прямого нижнего края — 10, 30, 50 мм и далее по возрастанию размера **только среди размеров отмеченных игроков текущего запуска резки**. Если выбран один размер, его отступ — 10 мм независимо от полного каталога. Кнопка создаёт отдельный лист купонов с разными ширинами и мостиками для пробной резки. Ушки учитываются при уплотнении и поворачиваются вместе с деталями только на 0°/180°; печатные детали и исходные лекала остаются прежними. Размеры ушка и режим сквозной резки нужно проверить на вашей ткани и лазере.

### Проба язычков для лазера

В резке добавлен выбор **«Прорезать размер внутри язычка»**: без него площадка остаётся цельной и размер различается положением язычка. Пресет **30×20 мм с мостиками по 4 мм** задаёт увеличенный вариант для пробы. Сравнительный лист содержит исходные 24×12 мм, увеличенные 30×20 и 40×25 мм, мостики 2/3/4 мм и пары с буквой и без неё. Мелкие прорезные коды убраны с купонов; размеры и обозначения находятся на отдельной странице-памятке с той же сеткой. Удачный размер нужно выбрать по результату своей резки; старые настройки автоматически не заменяются. Подробнее — в [SPORT_TEMPLATE.md](SPORT_TEMPLATE.md#лист-пробной-резки-язычков).

### Экспорт раскладки резки в DXF

В разделе **«Экспорт резки»** выберите отдельную папку и нажмите **«Экспортировать активный лист резки в DXF»**. Сохраняется только открытая страница резки или лист язычков для пробной резки, целиком, в **DXF AutoCAD 2000**, миллиметрах и масштабе **1:1**. Надсечки, язычки и буквы сохраняются векторами. Папка запоминается; каждый экспорт создаёт новый файл. Для нескольких листов переключайтесь между ними и повторяйте экспорт. Ранее добавленная кнопка сохранения CDR тоже доступна. Подробности — в [SPORT_TEMPLATE.md](SPORT_TEMPLATE.md#экспорт-листов-резки-в-dxf).

Нестинг резки после трёх первоначальных укладок дополнительно перебирает перестановки внутри страниц: перенос одной детали в конец может освободить центр и дать более плотную укладку остальных. Затем используются новые промежутки для деталей с последующих листов. Повороты остаются 0°/180°. Дополнительный поиск ограничен временем и принимает только улучшение по числу страниц, общей длине либо ровности низа при той же длине; оптимальная укладка не гарантируется. Размеры страницы и заданный зазор проверяются при размещении.

## Первая функция: trim bitmap

`src/BitmapTrim.bas` содержит макросы для обрезки прозрачной рамки у выбранных растровых изображений, аналогично Photoshop Trim по прозрачным пикселям.

Основной сценарий:

1. Выделить один или несколько PNG/bitmap объектов с прозрачностью.
2. Запустить `BitmapTrim.TrimSelectedBitmaps`.
3. Макрос найдет границы видимых пикселей по alpha channel и применит crop bitmap.

Настройки в начале модуля:

- `DEFAULT_ALPHA_THRESHOLD` - пиксели с alpha выше этого значения считаются видимыми.
- `DEFAULT_PADDING_PX` - дополнительный отступ в пикселях после тримминга.

## Вторая функция: contour cut для стикерпаков

`src/StickerCut.bas` автоматизирует контурный рез по выделенному стикерпаку.

Что делает макрос:

1. Дублирует выделенные объекты, не трогая оригинал.
2. Растрирует копию с прозрачным фоном.
3. Трассирует временный растр.
4. Создает общий внешний `Boundary`.
5. Оставляет внешние замкнутые линии, а внутренние пути (отверстия) удаляет по геометрическому вложению и направлению кривой.
6. Строит внешний offset в миллиметрах с круглыми углами и упрощает лишние узлы с заданным допуском.
7. Удаляет временные объекты и оставляет линии реза.

Основные команды:

- `StickerCut.CreateStickerCutContour` - спросить offset в мм.
- `StickerCut.CreateStickerCutContour1mm` - контур 1 мм.
- `StickerCut.CreateStickerCutContour2mm` - контур 2 мм.
- `StickerCut.CreateStickerCutContour3mm` - контур 3 мм.

В нативной панели можно настроить допуск упрощения контура в миллиметрах и размеры язычка: ширину, длину и радиус скругления.

Настройки в начале модуля:

- `DEFAULT_CUT_OFFSET_MM` - отступ по умолчанию.
- `DEFAULT_RASTER_DPI` - разрешение временной растризации.
- `DEFAULT_TRACE_SMOOTHING` - сглаживание трассировки.
- `DEFAULT_TRACE_DETAIL` - детализация трассировки.
- `DEFAULT_CUT_LINE_WIDTH_MM` - толщина линии готового контура.

## Как поставить в CorelDRAW

### 1. Создать VBA project

`.gms` бинарник нужно создать внутри CorelDRAW:

1. Открыть `Tools > Scripts > Scripts`.
2. Создать новый VBA macro project, например `VanyaTools.gms`.
3. Открыть VBA editor.
4. Импортировать `src/BitmapTrim.bas`.
5. Импортировать `src/StickerCut.bas`.
6. Запустить нужный макрос из `BitmapTrim` или `StickerCut`.

### 2. Поставить полноценную боковую панель

Готовый каркас CorelDRAW docker лежит в `addon/VanyaTools`.

После создания `VanyaTools.gms` скопировать его в эту папку:

```text
addon/VanyaTools/VanyaTools.gms
```

Затем скопировать всю папку:

```text
addon/VanyaTools
```

в CorelDRAW Addons folder, например:

```text
C:\Program Files\Corel\CorelDRAW Graphics Suite <version>\Programs64\Addons\VanyaTools
```

После перезапуска CorelDRAW панель должна появиться здесь:

```text
Window > Dockers > Vanya Tools
```

Внутри панели уже есть настройки contour cut: offset в мм, DPI временной растризации, smoothing и detail для трассировки.

### Быстрая установка скриптом

После создания `VanyaTools.gms` можно установить addon одной командой:

```powershell
.\install.ps1 -GmsPath "C:\path\to\VanyaTools.gms"
```

Если `VanyaTools.gms` уже лежит в `addon/VanyaTools/VanyaTools.gms`, достаточно:

```powershell
.\install.ps1
```

Если `.gms` еще не создан, скрипт все равно поставит боковую панель, но кнопки макросов начнут работать только после повторной установки с `-GmsPath`.

Строгий режим, который останавливается без `.gms`:

```powershell
.\install.ps1 -RequireGms
```

Если CorelDRAW установлен нестандартно:

```powershell
.\install.ps1 -CorelAddonsPath "C:\Program Files\Corel\CorelDRAW Graphics Suite 2024\Programs64\Addons"
```

Скрипт синхронизирует HTML-панель, копирует addon в папку CorelDRAW и не удаляет другие addon-папки.

## Источники API

- CorelDRAW поддерживает VBA macro projects в `.gms` и загрузку через Scripts docker.
- Custom dockers могут быть HTML-панелями, которые вызывают объектную модель через `window.external.Application`.
- `Bitmap.ImageAlpha`, `Bitmap.CropEnvelope` и `Bitmap.Crop` используются для работы с прозрачным bitmap и постоянной обрезкой.
- `ShapeRange.ConvertToBitmapEx` создаёт растр с прозрачностью; внешний контур строится напрямую по альфа-каналу. Для растра без прозрачности используется `Bitmap.Trace`; затем применяются `ShapeRange.CreateBoundary` и `Curve.Contour`.

### Цветопроба относительно эталона

**Выбор клиентом и повторение цвета:** создайте таблицу и сохраните CDR. Напечатайте её с производственными настройками и на нужном материале. Клиент сообщает код **CP-…** и номер под плашкой. В том же файле нажмите **«По номеру»**, выберите таблицу и введите номер: точный состав можно вернуть в эталон или создать отдельным образцом. Для старой таблицы без каталога выделите сам цветной прямоугольник и нажмите **«Выделение»**.

Выберите заливку объекта или цвет в палитре. В режиме сетки базовые значения можно также ввести вручную. Доступны три режима:

- **Таблица по каналам:** по умолчанию 15×15 плашек 20×20 мм, различия «Средне» (CMYK 3 / RGB 8). Два выбранных канала меняются по осям; серия и составные блоки включаются в «Дополнительно». Каждый образец получает обычный номер под цветной зоной. Номера идут слева направо и сверху вниз, сквозным порядком по всем листам серии. Плашки сохраняют заданный размер; под каждым микрорядом выделены 3,5 мм для подписей, между блоками по умолчанию 1 мм. Дополнительные уровни задаются отклонениями от эталона или абсолютными значениями. На границах каналов диапазон сдвигается целыми шагами с сохранением эталона; недопустимые сочетания отклоняются без повторов. Поля 8 мм, размер и число клеток настраиваются. Технические R/C/Q-подписи убраны с клиентской таблицы; точный состав и адреса сохранены в каталоге CDR. Эталон отмечен рамкой.

- **Наглядный:** отдельные ряды по светлоте, оттенку и насыщенности HSL, по 21 позиции: эталон в центре, 10 шагов влево и 10 вправо. Недопустимые или повторяющиеся после округления варианты оставляют пустую ячейку, сохраняя центр. Настраиваются шаги каждого свойства. Расчёт от RGB эталона; для вывода CMYK Corel преобразует варианты. Центральная метка использует точные компоненты эталона в выбранной модели.
- **Точный CMYK/RGB:** все сочетания отклонений, изменение одного канала или сетка по двум каналам. Списки задаются относительно эталона: при C=40 отклонения `-5 0 +5` дают C=35,40,45. Эталон включается всегда, недопустимые значения пропускаются, одинаковые сочетания не повторяются. Максимум 500 уникальных сочетаний; эталон может повторяться по центру каждого ряда.

Цветопроба создаётся на отдельной странице подходящего размера. В прежних режимах исходная заливка эталона показана отдельно, в таблице эталон отмечен тёмной рамкой, под образцами указаны фактические CMYK/RGB. В новой таблице под каждой плашкой стоит обычный номер, а эталон отмечен рамкой; цветная зона не содержит текста. Код таблицы и точные рецепты сохраняются в CDR. Для уточнения выберите подходящую плашку как новый эталон и повторите поиск меньшим шагом.
#### Локальная серия таблиц и Pantone

**«Несколько таблиц»** в разделе **«Дополнительно»** использует принцип таблиц принтера для небольших отклонений от выбранного эталона. По умолчанию создаются пять таблиц со средним шагом: 3 для CMYK или 8 для RGB; два других канала меняются по осям сетки. Выбор «Различия» также предлагает мягкий шаг 1/3 или контрастный 5/16 для CMYK/RGB; ручные значения сохраняются как «Свой шаг». В CMYK можно использовать блоки 2×2 с четырьмя уровнями оставшегося канала, в RGB — обычные плашки. Количество таблиц, шаг и свои отклонения между листами настраиваются. Это локальный поиск: полный диапазон каналов не перебирается. По умолчанию эта опция выключена и создаётся одна таблица.

Перед созданием показаны число таблиц, общее число плашек и диапазоны каналов. В схеме можно переключать таблицы. На каждой странице печатается отдельный исходный эталон; положение полного эталона внутри сетки указано только на таблице с нулевым отклонением. Все страницы проверяются заранее, создаются одной группой отмены и удаляются при ошибке создания серии. Серия ограничена девятью таблицами и 10 000 плашками.

**«Pantone»** сразу открывает окно и ищет ближайшие цвета установленной в Corel палитры по CIEDE2000 (ΔE00) в Lab. При необходимости можно указать локальную палитру Corel XML/CPL. Поиск использует текущие значения эталона CMYK/RGB; преобразование для сравнения выполняется на копиях, а выбранные плашечные заливки сохраняют native-цвет палитры. Результат создаётся отдельным листом с исходным эталоном, выбранными Pantone, именами и ΔE00. При отсутствии подходящей палитры выводится сообщение; подмена Pantone приблизительными RGB/CMYK не выполняется. Близость в Lab не гарантирует совпадения на конкретном материале: окончательное сравнение — по печатной пробе.

#### Цветопроба выбранным логотипом и ширина листа

В поле **«Образец»** выберите **«Покрасить логотип»**, выделите одноцветное векторное лого, текст или группу и нажмите **«Взять логотип из выделения»**. Цвет эталона берётся из лого; его можно заменить цветом из палитры. Варианты окрашивают все однородные заливки и видимые обводки копии. Размер, пропорции, структура и расположение элементов сохраняются 1:1. Растры и градиенты не поддерживаются в этом режиме. Исходные объекты не редактируются; для создания копий должен быть открыт тот же CDR.

Ширина листа задаётся отдельно, по умолчанию **570 мм**, и запоминается. Поля — по 8 мм. Квадраты занимают всю полезную ширину по 21 ячейке, зазор между ячейками 1,5 мм. Логотипы остаются 1:1, располагаются по центрам доступного нечётного числа ячеек; подпись с CMYK/RGB размещается одной строкой под образцом. Если все 21 логотип не помещаются, дополнительные пары вариантов продолжаются ниже с повторением центрального образца; продолжения подписываются. Размер логотипа автоматически не уменьшается. Например, лого 100×50 мм укладывается по пять в ряд на листе 570 мм. Длина страницы рассчитывается по всем рядам, до предела Corel 45 м.

#### Выбор игроков для печати и большая таблица

В таблице игроков спортформы есть галочка **«Печатать»**; новые и ранее сохранённые строки без этого поля включены по умолчанию. **«Печатать всех»** и **«Снять все»** меняют весь список. Этап 2 и резка используют только отмеченные строки; количество комплектов считается по ним. Состояние галочек сохраняется вместе с черновиком. Вставка поверх существующих строк сохраняет галочки; новые строки отмечены.

**«Открыть таблицу большим окном»** открывает тот же редактор в отдельном окне с изменяемым размером: вставка Excel/Google Таблиц, назначение размеров, галочки и кнопки допечатки доступны там же. После закрытия редактор возвращается в докер с текущими данными. Кнопка ↗ по-прежнему создаёт одну деталь выбранного игрока независимо от флажка массовой печати.
#### Прежние способы: 21 ячейка

Квадраты теперь рассчитываются по ширине плёнки, без выбора 3/5/7 вариантов или ручного размера плашки. По умолчанию лист 570 мм, поля по 8 мм, зазор 1,5 мм: квадрат около 24,95 мм. **11-я ячейка — эталон**, слева 10 уменьшений, справа 10 увеличений. Для наглядного поиска и режима одного канала позиция эталона остаётся фиксированной, даже если цвет достиг границы или округление даёт повтор. На месте недоступной плашки остаётся тонкая пустая рамка. Для двух каналов строки соответствуют изменениям второго канала, эталон — в строке нулевого изменения и центральной колонке. В переборе сочетаний центральный эталон повторяется в каждом ряду, сочетания делятся по знаку первого отличающегося канала и близости к эталону.

Под каждым образцом только одна строка фактического цвета: `R:184 G:9 B:127` либо `C:0 M:80 Y:20 K:0`. Дополнительные подписи смещения под плашками убраны. Вертикальный шаг — высота образца +9 мм, компактная шапка занимает 16 мм. Эталон квадратов выделен тёмной рамкой.

В прежних способах шаг по умолчанию **1**. Наглядный поиск допускает значения от **0,1** (включая запись `0,5`). CMYK/RGB в используемом Corel API имеют целые компоненты: минимальный точный шаг **1**. При дробном наглядном шаге одинаковые после преобразования цвета не печатаются повторно.

Логотипы сохраняют **1:1**. Число колонок — максимально помещающееся нечётное, до 21. Например, для лого 100×50 мм на листе 570 мм остаётся 5 колонок, эталон в третьей; ряды показывают следующие пары отклонений. При одной колонке варианты печатаются последовательно каждый отдельным рядом, без уменьшения.
